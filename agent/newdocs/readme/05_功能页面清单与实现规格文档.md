### 2.2 核心交互行为与业务逻辑
1. **排期计划驱动任务实例**：
   * 在“排期规则”中新建计划，选择“生态环境局 + 碳排放报告 + 月度”；
   * 系统自动计算首期生成日与截止日，生成日在当期的任务自动在“报送任务”置顶呈现。
2. **缺项极速补录通道**：
   * 进入阶段二，表格输入框旁检测到上期基准，自动浮出微型胶囊 `[引用上期(450.0万kWh)]`；
   * 表头提供 `[引用基准补全本表]` 批量补全按钮，点击后一秒完成全表缺项补齐，闸门放行。
3. **监管合规体检定心丸**：
   * 阶段三顶部置顶呈现【监管预审合规体检卡】，自动核算格式符合度、勾稽平衡度与阻断清零状态；
   * 阻断清零后显示绿色结论：`✓ 具备法定上报合规性（预计一次性受理通过率 100%）`。
4. **数据源头全链路穿透**：
   * 阶段三附表及阶段四定稿通读表格中，任意数值点击立即唤起右侧抽屉；
   * 直观展示：当前报告值 → 法定折算公式与因子 → 底层物理表计编号、原始读数、采集时间戳及防篡改验签状态。

### 2.3 全局数据字典对齐表（样例）

### 2.4 验收准则与测试用例 (Checkpoints)
* **TC-01（闸门阻断测试）**：阶段二若存在未填字段或未处置的阻断项，进入阶段三的按钮必须为物理置灰状态（`disabled=true`），提示“待缺项清零后放行”。
* **TC-02（AI 数值护栏测试）**：阶段三执行正文润色时，若模拟改写篡改了正文中的数值，必须提示“改动不可接受”并物理禁用“接受”按钮。
* **TC-03（穿透有效性测试）**：点击阶段四定稿表格中“净购入电量”，抽屉必须正确带出电表编号 `EM-0104`、原始读数及时间戳。
