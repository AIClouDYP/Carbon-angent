## 一、 业务场景矩阵与向导形态分类

### 1.1 业务子场景矩阵全景
系统划分为三大业务方向，包含若干独立业务智能体场景：
1. **碳核算与足迹类**：产品碳足迹 (CFP)、产品环境足迹 (PEF)、组织碳核算、园区碳核算、地方碳市场管控；
2. **绿色创建与评价类**：零碳工厂智能申报、绿色工厂评价对标；
3. **周期法定报送类**：多源数据智慧报告中枢（对接生态局、统计局、发改委等）。

### 1.2 三大典型流转形态定义
* **形态 A：九阶段全生命周期流（核算类主线）**：
  `政策标准匹配 → 边界界定 → 工艺/组织建模 → 活动数据采集 → 缺项补录 → 排放计算 → 敏感度/情景分析 → 报告产出 → 归档`
* **形态 B：六阶段双轨申报流（评价类主线）**：
  `标准锁定 → 指标体系建模 → 数据与佐证收集 → 两级核算判定 → 差距分析与优化路径 → 申报材料汇编`
* **形态 C：周期性报送流（法定报送主线）**：
  `排期自动驱动任务 → 范围与主体核对 → 通用底座数据吸纳与质检 → 单任务法定口径折算校验 → 签字归档与源头穿透 → 官方回执闭环`

## 二、 核心业务场景逐项梳理（以智慧报告为例）

> *【编写指引】针对每一个业务子场景，按“定义目标 → 端到端泳道图 → 阶段状态机 → 人机分工”四部分标准化展开。*

### 2.1 智慧报告智能体（周期性报送中枢）

#### 2.1.1 场景定义与业务目标
* **业务定位**：企业与园区面对政府多部门能碳报送的“集中编排与归档中枢”。
* **核心目标**：实现“底层一套数、任务单口径、规则防漂移、数字直穿源头、官方回执闭环”。

#### 2.1.2 端到端业务流程泳道图

#### 2.1.3 领域阶段状态机与流转硬闸门
* **阶段一（Scope · 模板匹配与主体核对）**：
  * *输入*：企业基础信息、上级主管部门报送任务要求；
  * *处理*：匹配平台模板库，锁定版本（`templateLock`），裁定适用报表与豁免清单；
  * *流转闸门*：主体信息核验无误，模板版本已锁定。
* **阶段二（Hydration · 数据采集与补录）**：
  * *输入*：通用基础数据底座（SCADA在线表计、MES产量、ERP发票）；
  * *处理*：质量守卫检测（精度合规、非正值过滤、±50%极值波动拦截），缺失项支持上期基准一键填入；
  * *流转硬闸门*：**缺项清零 + 阻断清零（或全部完成工况豁免留痕）**。
* **阶段三（Verification · 生成与校验）**：
  * *输入*：已通过质检的完整采集底数；
  * *处理*：规则引擎自动折标，受控 AI 进行正文叙述润色（带改写护栏），格式合规与勾稽平衡双引擎校验，生成【监管预审合规体检卡】；
  * *流转硬闸门*：校验阻断清零，具备法定上报合规性。
* **阶段四（Filing · 确认归档与穿透）**：
  * *输入*：定稿版式预览；
  * *处理*：公文通读、表格任意数值直穿底层原始表计/发票台账、SHA-256防篡改存证单生成、多格式带水印导出、登记提报回执闭环。

#### 2.1.4 人机协作分工与责任红线
* **系统/引擎 100% 自动包揽**：折标煤与碳排放数值运算、加总勾稽平衡、极端波动检测、版本锁定、数字指纹计算。
* **业务人员保留裁定权（不得被AI越权）**：异常工况原因选择与豁免说明录入、正文润色文本的最终确认、公文电子签字加盖公章、上报凭单回填。

## 三、 支撑底座与各业务场景的调用拓扑

### 3.1 业务场景与两大支撑模块的解耦关系
```
┌────────────────────────────────────────────────────────┐
│ 业务场景层：足迹 CFP / 组织核算 / 智慧报告 / 零碳工厂 ... │
└──────────────┬──────────────────────────┬──────────────┘
               │ 共享调度                 │ 归档与消费
┌──────────────▼──────────────┐   ┌───────▼──────────────┐
│  运维管理模块（公域规则库）  │   │  组织资源模块（私域台账库）│
├─────────────────────────────┤   ├──────────────────────┤
│ • 政策标准库 (标准与条款解析) │   │ • 报告与档案中心 (归档底卷) │
│ • 排放因子库 (官方缺省公因数) │   │ • 企业因子库 (实测私因数)   │
│ • 核算公式库 (物理确定性算法) │   │ • 佐证材料库 (发票/证书凭据)│

└─────────────────────────────┘   └──────────────────────┘
```

### 3.2 因子与规则调度优先级闭环
1. 公式库声明输入指标与参数域；
2. 因子匹配引擎自动检索：**企业实测私因数（P-1）→ 企业历史记忆（P0）→ 规则表 → 平台公域缺省因数（P-兜底）**；
3. 人工纠偏结果回写企业私域台账，算法规则由 Skill 管理运维升级。
