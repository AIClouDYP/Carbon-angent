# 产品环境足迹工作台（/#/agent-center/apps/pef-accounting）

> 模块：pef-accounting ｜ 文件：`agent-center/views/PefAccountingCenter.vue`（中心页）+ `accounting/agent.vue`（九阶段工作台）
> 对应标书：2.7.3 产品环境足迹智能体 ｜ 状态：✅ **已实现（2026-10-20：基于产品碳足迹九阶段工作台整体移植 + 多环境影响类别）**

## 1. 业务场景定位

面向出口企业，按 **欧盟 PEF 方法论 / PEFCR 类目规则**对产品开展全生命周期（LCA）**多环境议题**核算，产出**碳足迹 + 水足迹 + 酸化 + 富营养化 + 资源消耗**等多指标环境足迹声明，支撑碳标签、绿色贸易壁垒应对与客户尽调。

与产品碳足迹（PCF）的差异：

| 维度 | 产品碳足迹（PCF） | **产品环境足迹（PEF）** |
|---|---|---|
| 评价对象 | 单一气候变化影响 | **16 项中点指标（EF 3.1），可选 5 类** |
| 标准体系 | ISO 14067 / GB/T 24067 / QC/T | **EU PEF 方法论 + ISO 14040/14044 + GB/T 24040/24044**，叠加 PCF 标准 |
| 结果形态 | 单一碳足迹值（kgCO₂e） | **类别 × 生命周期阶段 影响矩阵** + 各类别合计 |
| 特征化 | GWP 单一因子 | **EF 3.1 十六项中点指标**（CC/WU/AP/EP-fw/RU-fos/OD/HT-c/HT-nc/PM/IR/POCP/EP-ter/EP-mar/ET-fw/LU/RU-mm）|
| 工作流 | 九阶段（目标范围→清单→影响评价→报告） | **同构九阶段**（复用），阶段三增加影响类别选择 |

## 2. 页面布局（中心页 + 工作台 两段式，与产品碳足迹同构）

```
① 中心页 /agent-center/apps/pef-accounting  （PefAccountingCenter.vue）
   历史对话栏 | 对话区（欢迎语三段卡片 + 指令） | 右侧面板（任务列表 / 产品库 双页签）
        ↓ 点击任务 / 一键核算
② 九阶段工作台 /pef-accounting/accounting/agent  （accounting/agent.vue）
   历史对话栏 | 对话区（阶段推进 / 确认 / 建议值） | 右侧工作区（九阶段面板）
```

**中心页（E-00）**：
- 右侧面板双页签：**任务列表**（搜索 + 任务卡片：名称/产品/进度条/状态标签/当前阶段/更新时间）、**产品库**（产品 → SOP → 一键核算）
- 欢迎语三段卡片：**核心能力** / **产品与物料库** / **当前状态**（任务统计）
- 新建任务：对话内嵌表单（任务名称 / 核算产品 / 核算标准）
- 与 PCF 中心页**完全同构**，仅业务口径不同（标准选项、任务数据、术语）

**工作台（九阶段）**：
- 阶段一~九：政策分析 → 核算边界 → 核算模型 → 活动数据 → 核算因子 → 数据校验 → 影响计算 → 分析 → 报告
- 边界配置含**影响类别**选择（12 类选 5），结果页含**多类别影响矩阵**

## 4. 功能点详情

### E-04 边界配置（影响类别）

- **交互**：边界配置 5 步（范围 → 单位 → 分配 → 取舍 → 时间边界）+ 第 6 步「影响类别」多选芯片。
- **规则**：**16 项中点指标**（EF 3.1；默认选中气候变化 / 水资源消耗 / 酸化 / 富营养化-淡水 / 资源消耗-化石），至少保留 1 类；选中项以类别色描边并打勾。
- **数据**：`impactCategories`、`boundaryConfig.selectedImpactCategoryIds`、`toggleImpactCategory()`。
- **验收**：`[x]` 16 类可选、默认 5 选；`[x]` 至少保留 1 类；`[x]` 边界摘要显示所选类别。

### E-08 影响计算与结果

- **交互**：阶段 7 展示结果横幅（最终环境影响结果）+ **多类别影响矩阵** + 树形表（单元过程排放贡献）+ 导出。
- **矩阵**：行 = 所选影响类别，列 = 5 个生命周期阶段 + 合计；气候变化列直接取各阶段碳排放，其余类别按预设特征化系数推算。
- **数据**：`impactMatrixData`（类别 × 阶段 × 合计）、`emissionTreeData`、`totalCarbonEmission`。
- **验收**：`[x]` 矩阵随所选类别变化；`[x]` 气候变化列与碳排放一致；`[x]` 合计列正确。

### E-07 因子匹配

- **因子库**：Ecoinvent 3.10 / ELCD / IPCC / CPCD / 国家温室气体排放因子数据库（ELCD 演示为未开通）。
- **匹配**：按 `matchFactor(item, 'footprint', { region, standard, stageKey })` 匹配，支持优先级与替代候选。

### E-09 报告与溯源

- **报告**：环境足迹声明（模板 `PEF-DECLARATION`），含核算边界、量化单位、取舍规则、不确定性声明。
- **溯源**：`traceabilityData`（活动数据 / 特征化因子 / 数据质量说明），DQR 四维评分。
- **核查**：推荐核查机构（CQC / SGS / BV / TÜV 等）。

## 5. 标准体系（与政策标准库打通，只显示适用标准）

工作台标准列表直接读**政策标准库**中 `scenarios` 含 `PEF` 的条目，按优先级排序：

| 顺序 | 标准 | 定位 | 说明 |
|---|---|---|---|
| 1 | **EU PEF 2021/2279** | 主方法论 | PEF Guide（替代 2013/179/EU），含 PEFCR 类目规则、16 项影响类别与归一化加权 |
| 2 | **ISO 14040/14044** | 方法学基础 | LCA 原则与框架 / 要求与指南，PEF 的底层方法 |
| 3 | **ISO 14067:2018** | 类别方法 | 单类别碳足迹方法，对应「气候变化（CC）」类别 |

**选择与解析联动**：
- 标准区默认以**一行**展示当前标准（编码 + 名称 + 已选中徽标），点击「切换标准」展开候选列表，选中后自动收起（无比较需求，避免列表长期占位）；默认选中第一条（EU PEF 2021/2279），若任务/偏好中的标准已不在列表则自动回落
- 下方「标准内容解析」随选中标准**动态渲染**（适用范围 / 边界界定 / 量化单位与分配 / 数据与因子要求 / 校验与报告），展示的是**标准条款本身**，不含具体产品信息（单位定义统一表述为“由企业按具体产品确定”）

**已排除（不适用 PEF）**：

| 标准 | 排除原因 |
|---|---|
| ISO 14025（EPD）| Ⅲ型环境声明体系（PCR 规则），与 PEF（PEFCR）并行而非包含 |
| ISO 14046（水足迹）| 采用 WFP 方法，与 PEF 的「水资源消耗（AWARE）」口径不同 |
| GB/T 24040/24044、GB/T 24067 | 与 ISO 14040/14044、ISO 14067 内容等价（等同/修改采用），避免重复 |
| QC/T 1248、PAS 2050、CBAM | 行业专用 / 已废止 / 申报规则，非 PEF 核算方法 |

> 上述标准仍可在**政策标准库**中查看与维护，只是不出现在 PEF 工作台的标准选择列表。
