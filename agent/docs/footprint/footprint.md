## 1. 业务场景定位

面向园区制造企业的碳管理人员与工艺工程师，基于 LCA 生命周期方法提供产品碳足迹九阶段智能核算服务（目标与范围界定、清单分析、影响评价、结果解读全流程），支撑绿色供应链查询、产品出海合规与客户碳问卷回复。业务入口为对话式引导：输入产品名称即可创建核算任务。

## 2. 页面布局

三个区域：历史对话栏（可收缩）| 对话区（智能体/任务两种模式）| 九阶段进度面板（轨道+侧边栏）
子视图：数据采集页、排放明细页；弹窗：CreateTaskDialog

## 4. 功能点详情

- 任务模式切换：pageMode = 列表 / task-active（进入任务后切换为九阶段界面）
- 阶段推进：对话确认推进当前阶段，currentStepIndex 递增、进度条同步，每阶段输出确认后锁定
- 边界配置确认（阶段一）：五项配置逐项确认，未确认核算标准时侧边栏显示占位
- 建模校核（阶段二~三）：模型视图中单元过程与数据项/因子关联可调整
- 数据质检（阶段四~六）：双页签分别处理 missing（danger）与 warning 项，按生命周期阶段归类
- 任务管理：删除仅限已完成任务；进度按 currentStepIndex/8 百分比展示

> **数据项与来源**：核算任务（currentStepIndex/productName/适用标准）、工艺流程图与 BOM 上传件、单元过程模型、活动数据质检结果、排放因子引用记录——见 _data-dictionary.md

**边界**
- 工艺流程图解析失败 → 降级为按行业通用模板手工搭建模型
- 必填边界配置未确认 → 无法进入建模阶段
- missing 项未补齐 → 计算阶段阻断
- 任务删除仅限已完成任务

**验收要点**
- [ ] 输入产品名称即可创建任务并出现在任务列表
- [ ] 九阶段进度条随对话确认正确推进
- [ ] 数据质检双页签分级展示且可定位到生命周期阶段
- [ ] 报告导出章节结构与标准要求一致

## 5. 政策分析（阶段一）标准区与解析区

- **标准区**：默认以一行展示当前标准（编码 + 名称 + 已选中徽标）；点击「切换标准」展开候选列表，选中后自动收起。默认选中列表第一条；若任务自带标准已不在列表则自动回落。
- **解析区**：随选中标准**动态渲染**标准条款（适用范围 / 系统边界 / 量化单位·分配规则·取舍与时间边界 / 数据与因子要求 / 校验与报告要求），内容为**标准要求本身**，不含具体产品信息。
- **职责边界**：阶段一讲"标准怎么要求"，阶段二（核算边界）填"本产品怎么算"（声明单位、核算期等产品级配置）。
