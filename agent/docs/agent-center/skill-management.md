# Skill 管理（Skill Management）

> 所属菜单：运维管理 → Skill 管理
> 页面路由：`/agent-center/apps/skill-management`
> 代码位置：`src/pages/zcip/agent-center/views/SkillManagement.vue`、`src/pages/zcip/agent-center/data/skillPrompts.js`
> 原型边界：不接后端、不执行真实大模型；页面只维护 Prompt 模板和启用状态，业务页在模拟解析前读取配置。

## 1. 业务场景定位

Skill 管理是智能体能力的配置入口，负责维护各阶段智能体使用的 Prompt 模板、启用状态和修改状态。它的核心价值是让解析规则可在线调整，而不是散落在业务页硬编码。

当前页面定位是前端原型配置台：

- Prompt 是模板文本，不是模型执行结果；
- 配置保存在浏览器 `localStorage`；
- 业务页面读取配置后仍然执行规则化模拟；
- 后续接入真实模型时，只需替换业务页的执行层，配置契约保持不变。

## 2. 页面布局

页面由三部分组成：

```text
┌────────────────────────────────────────────────────────────┐
│ 页头：Skill 管理 / 维护各智能体的 Prompt 模板                │
├────────────────────────────────────────────────────────────┤
│ 列表工具条：适用阶段 / 知识库 / 状态 / 关键字 / 重置          │
│ Skill 表格：名称 / 功能描述 / 状态 / 模板状态 / 详情 / 操作  │
│ 分页栏                                                      │
└────────────────────────────────────────────────────────────┘
```

辅助交互：

- 编辑模板弹窗：Prompt 文本编辑、实时字数、预览效果；
- Prompt 预览弹窗：模拟变量替换与高亮；
- 详情抽屉：640px，无 Element 默认 header，自定义信息头、属性标签、统计卡、变量区和 Prompt 卡片。

## 4. 功能点详情

### S-01 Skill 列表

- **位置**：页面主体表格。
- **交互**：名称列显示图标和名称；描述列超长省略；状态列展示启用/禁用；模板状态展示默认/已修改。
- **边界**：列表数据来自 `DEFAULT_SKILLS` 深拷贝，`mounted()` 后与本地缓存合并。
- **数据**：Skill 配置对象；`id` 是稳定唯一键。
- **验收**：默认 10 个 Skill 都可见；修改和禁用状态能如实显示。

### S-02 条件筛选

- **位置**：列表工具条。
- **交互**：适用阶段、知识库、状态为下拉；关键字模糊匹配名称、描述、阶段、知识库、Prompt；重置清空所有条件。
- **边界**：阶段和知识库选项由当前数据动态生成；知识库 `—` 不进入知识库筛选；任何筛选变化都回到第一页。
- **数据**：`filteredSkills` 计算属性 + `pagedSkills` 分页。
- **验收**：多个条件叠加生效；关键字命中 Prompt 内容；分页大小切换不错位。

### S-03 启用/禁用

- **位置**：表格操作列。
- **交互**：点击「禁用」或「启用」后立即写回当前行，更新 `updatedAt` 并持久化。
- **边界**：`enabled` 不是纯展示状态；业务页会调用 `isSkillEnabled(skillId)`。禁用「标准解析」会阻断政策标准库的模拟解析入口。
- **数据**：`enabled: boolean`。
- **验收**：禁用后进入政策标准库上传解析时不会生成解析草稿。

### S-04 Prompt 编辑

- **位置**：「编辑模板」弹窗。
- **交互**：编辑器加载当前行深拷贝；顶部提示花括号变量不可修改；底部显示字符数；保存触发变量校验。
- **边界**：只校验原变量丢失，不校验新增变量；未保存编辑不影响表格行。
- **数据**：`editingSkill`、`originalTemplate`；`extractVariables(template)` 提取 `{{\w+}}` 变量并去重。
- **验收**：删除任一原变量时保存被阻断；描述文字可修改；保存后 `modified` 与 `updatedAt` 正确更新。

### S-05 Prompt 预览

- **位置**：编辑弹窗内的「预览效果」。
- **交互**：用固定示例数据替换部分变量，替换值以高亮样式显示。
- **边界**：示例数据只用于前端模拟，不代表真实输入；示例值先 `escapeHtml()` 再插入；未命中的变量保留原样。
- **数据**：`sampleData`、`previewContent`。
- **验收**：变量高亮可辨识；用户描述文字不会被示例数据覆盖；弹窗关闭不污染原模板。

### S-06 恢复默认

- **位置**：仅 `modified === true` 的行显示。
- **交互**：确认后按 `row.id` 从 `DEFAULT_SKILLS` 找默认 Prompt 并写回。
- **边界**：只恢复 Prompt 和模板状态，不重置启用状态和 `updatedAt`。
- **数据**：默认来源 `DEFAULT_SKILLS`。
- **验收**：恢复后 Prompt 与默认一致，`modified` 回到 false，配置继续持久化。

### S-07 详情抽屉

- **位置**：表格「详情」列。
- **交互**：
  - 信息头：实色图标、名称、描述、右上角关闭按钮；
  - 属性标签：阶段、知识库、启用状态、模板状态；
  - 统计卡：变量数量、最近修改、Prompt 字数、默认来源；
  - 输入变量：等宽标签展示；
  - Prompt 模板：保留换行、内部滚动、可复制。
- **边界**：抽屉关闭 Element 默认 header，避免双重标题；`detailSkill` 直接引用表格行，抽屉内不直接编辑。
- **数据**：`detailVariables` 由 Prompt 实时提取。
- **验收**：只有单一标题；关闭按钮、遮罩和 ESC 都可关闭；复制成功或失败均有提示。

### S-08 配置持久化

- **位置**：`persistSkills()`、`loadSkills()`。
- **交互**：启用/禁用、保存模板、恢复默认后保存完整 `skills` 数组；页面进入时与默认配置合并。
- **边界**：
  - key 为 `carbon-skill-templates`；
  - 默认配置作为 base，本地缓存按 `id` 覆盖；
  - JSON 解析失败时回退默认配置；
  - 旧缓存对象的字段会整体覆盖默认配置，不做字段级兜底。
- **数据**：见全局数据字典 `carbon-skill-templates`。
- **验收**：刷新后配置保留；新增默认 Skill 能出现在列表；默认 Prompt 升级时未被用户修改的 Skill 能取新值。

### S-09 跨页消费

- **位置**：`skillPrompts.js` 导出函数，当前消费方是 `StandardsLibrary.vue`。
- **交互**：政策标准库在 `runSkillParse()` 先判断 `standard-parsing` 是否启用；启用后调用 `getSkillConfigById('standard-parsing')` 读取 Prompt。
- **边界**：
  - `getSkillConfigById()` 优先返回本地缓存配置，找不到时返回默认配置；
  - `isSkillEnabled()` 找不到配置时视为启用；
  - 当前只把 Prompt 和状态写入 `parseMeta`，不执行 Prompt。
- **数据**：Skill id、`promptTemplate`、`enabled`。
- **验收**：禁用后解析流程中断；启用后 `parseMeta` 能记录模板修改状态、更新时间、Prompt 和来源文件。

## 5. 数据模型

默认配置对象字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 稳定唯一键，业务页按 id 查配置 |
| `name` | string | 展示名称 |
| `phase` | string | 阶段标签，如「阶段一 · 政策标准解析」 |
| `icon` | string | Element 图标类名 |
| `color` | string | 列表图标和详情头部颜色 |
| `desc` | string | 功能描述，参与关键字搜索 |
| `enabled` | boolean | 启用状态 |
| `modified` | boolean | 当前 Prompt 是否偏离默认 |
| `knowledgeBase` | string | 关联知识库；`—` 表示无强关联 |
| `updatedAt` | string | 最近修改时间 |
| `promptTemplate` | string | Prompt 模板全文 |

| id | 名称 | 阶段标签 | 知识库 |
| --- | --- | --- | --- |
| `standard-parsing` | 标准解析 | 阶段一 · 政策标准解析 | 政策标准库 |
| `boundary-config` | 边界配置 | 阶段二 | 政策标准库 |
| `process-modeling` | 工艺建模 | 阶段三 | — |
| `data-collection` | 数据采集 | 阶段四 | — |
| `factor-annotation` | 因子标注 | 独立能力 | 排放因子库 |
| `factor-matching` | 因子匹配 | 阶段五 | 排放因子库 |
| `data-validation` | 数据校验 | 阶段六 | 政策标准库 |
| `calculation-orchestration` | 计算编排 | 阶段七 | 计算公式库 |
| `analysis-orchestration` | 分析编排 | 阶段八 | — |
| `report-generation` | 报告生成 | 阶段九 | — |

## 6. 后续接入改造点

| 主题 | 当前状态 | 后续方向 |
| --- | --- | --- |
| 持久化 | 仅浏览器 localStorage | 按用户/租户迁移到后端配置接口 |
| 默认版本 | 没有默认模板版本号或 hash | 增加默认版本，区分内置升级与用户修改 |
| 变量校验 | 只校验原变量丢失 | 增加未注册变量提示和变量来源登记 |
| 预览安全 | 只转义变量值 | 先整体 HTML 转义文本，再插入高亮片段 |
| 执行链路 | 业务页规则化模拟 | Prompt 与文件列表提交真实模型服务 |
| 消费范围 | 只有标准解析被业务页消费 | 按阶段逐个接入运行时 |
