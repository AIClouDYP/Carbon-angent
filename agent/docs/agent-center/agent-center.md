## 1. 业务场景定位

智能体中心是全部智能体的统一入口与公共资源底座，按“公域权威规则 / 私域企业台账”分界：

- **应用中心**：管理各类智能体应用（应用中心、碳核算中心），承载智能体矩阵的入口导航；
- **资源库群 · 公域规则库**：支撑智能体运行的权威规则与配置资产——政策标准库、排放因子库、核算公式库、单元过程库、平台模板库、Skill 管理、组织模板库；
- **资源库群 · 私域台账库**：企业侧数据资产——组织资源库、企业因子库、佐证材料库、产品与物料库、产品 SOP 库、改善措施库、报告与档案中心。

对应智能体设计理念中「标准即配置、技能库、知识库」的页面载体：业务场景只消费库，不重复维护规则本体。

## 2. 页面布局

- **应用中心**（A-01/A-02）：左对话区 + 右智能体/任务列表的“应用二层结构”，卡片列表 + 分类导航；
- **资源库群**（A-07~A-20）：统一列表页范式——顶部工具条（搜索 / 筛选 / 新建 / 导入导出）+ 中部表格 + 右侧详情抽屉 / 独立详情页（政策标准库走独立详情路由 `/standards-library/detail`）；
- **智能体应用内布局**：`AgentAppLayout`（A-03）提供统一外壳（左历史对话 + 中对话区 + 右信息/结果面板），`CarbonRightPanel`（A-04）为碳核算类右侧面板；
- 未开发入口由 `PlaceholderPage`（A-06）承接。

## 4. 功能点详情（按视图分节）

### 4.1 应用中心（A-01 / A-02）
- **位置**：模块入口页；A-02 为应用二层页
- **交互**：应用卡片按分类展示，点击进入对应智能体工作台；二层页左侧对话、右侧任务列表，支持新建核算任务并跳转
- **边界**：应用中心只做入口导航与任务清单，不承载核算逻辑（核算在工作台内）
- **数据**：智能体应用清单、核算任务列表（会话与任务索引）
- **验收**：[ ] 卡片点击进入正确工作台；[ ] 二层页可新建任务并跳转

### 4.2 公共布局与引导（A-03~A-06）
- **位置**：被各智能体应用复用（组件级）
- **交互**：A-03 提供统一三栏外壳与主题；A-04 承载右侧信息/结果面板；A-05 首次进入时的分步引导与模板章节预览；A-06 承接未开发路由
- **边界**：组件不持有业务数据，数据由宿主页面注入；A-06 占位页仅提示“开发中”，不产生副作用
- **数据**：由宿主页面传入（无自有持久化）
- **验收**：[ ] 各应用外壳一致；[ ] 引导可跳过且不阻塞；[ ] 未开发入口有占位提示

### 4.3 资源库群：统一交互范式（A-07~A-20）
- **位置**：资源库群各视图（列表 + 详情）
- **交互**：统一范式——检索、筛选、增删改查、批量导入导出、版本管理；列表行点击打开详情（抽屉或独立详情页）
- **边界**：库为**配置/台账载体**，不承载业务计算；字段与术语口径统一登记在 [_data-dictionary.md](../_data-dictionary.md) 与 [_terms.md](../_terms.md)，页面不重复定义
- **数据**：各库 mock 数据（生产环境为库表 + 对象存储）
- **验收**：[ ] 各资源库增删改查与导入导出可用；[ ] 因子/标准/公式的引用关系与智能体核算链路一致

### 4.4 重点库的差异点

| 视图 | 关键差异 |
|---|---|
| **A-08 排放因子库** | 因子智能匹配的数据源；支持自定义因子替换与适用条件维护；分模块存储国内官方因子 / 企业实测因子 / 分时分区电力碳因子 / 国际主流因子，含可信度评分与版本回溯 |
| **A-07 政策标准库** | 标准条文结构化存储（标准解析 → 结构化配置段）与详情穿透（独立路由）；支撑知识向量库构建；上传解析标准后进入“待人工审核”，审核通过方对智能体生效 |
| **A-11 平台模板库** | 报告模板载体：`reportType / docName / version / prefill / variants / matchFields / periods / sections / body / caliber`；智慧报告按 `reportType` 匹配模板，`caliber.standardCode` 引用政策标准库规则集 |
| **A-14 组织资源库** | 主体与表计档案台账，是资格核验（法人 / 规模 / 名单）与场景路由（行业 / 领域）的数据来源 |
| **A-15 企业因子库** | 与 A-08 公因数**分库**：企业实测与历史记忆（P-1 / P0）私域存放，人工纠偏结果回写本库 |
| **A-20 报告与档案中心** | 归档底卷与报告资产库；承载报告查看 / 下载 / 全宗底卷查验（工作台存证底卷抽屉的穿透目标） |

### 4.5 跨视图：业务场景对基础库的需求登记

基础库演进以业务场景需求为输入（登记后进入细化设计）：

- **平台模板库 ← 智慧报告（R-05 临时报告）**：模板需维护 **periods（支持的报送周期）**，供报告类型按时间维度自动过滤（PT-009~016 已配置；reportType/scopes 亦被类型下拉展示引用）。管理页表单暂未提供 periods 编辑入口（当前由代码侧维护），后期补表单多选——已列待开发。
- **平台模板库 ← 智慧报告（R-08 编制依据）**：报告模板结构必须保留 **caliber 编制依据引用声明，单键 standardCode（→ 政策标准库规则集）**——依据名称由 standardCode 从标准库解析获得（模板不重复声明），公式标准 / 因子版本属平台内部配置（公式库 / 因子匹配服务管理），不作依据展示。语义：模板是引用的**唯一声明点**，解析模板即自动解析出全部依据链（任务创建时快照完整拷贝 → 按 standardCode 自动关联标准库本体），填报人在任务内零操作。要求：① **standardCode 的录入方式 = 模板配置表单提供标准库下拉选择**（REPORT 场景条目，选中即带出依据名称——原型中为人工配置写死，非解析所得，细化设计改为表单交互）；② standardCode 必须能在政策标准库中命中（REPORT 场景）——**模板保存时应做命中校验**（当前缺失，已列待办）；③ 任务快照必须完整拷贝 caliber 对象；④ 引用与本体分离——模板改引用、标准库升本体，互不耦合（PT-009~016 已配置）；⑤ 远期：规范 docx 上传解析辅助生成引用声明草稿（人工确认）。
- **政策标准库 ← 智慧报告（R-08 编制依据）**：REPORT 场景规则集种子已入库（附件2 / GB/T 32150-2015 / GB/T 17166 / 部门口径条目等，ensureSeed 幂等合并）；**待办——标准库管理页 persistCustomStandards 为整体覆盖写入，可能抹掉种子条目，需改为 load-modify-save**；智慧报告侧已做源常量兜底不受影响。
- **组织模板库 ← 零碳工厂（ZC-10）**：确认核算模型落库、同类申报复用——代码未实现，规划中（见 [TaskWorkbench.md](../zero-carbon-factory/TaskWorkbench.md)）。

> **数据项与来源**：platformTemplates.js（模板库）、各库 mock 数据——见 [_data-dictionary.md](../_data-dictionary.md)

**边界（模块级）**
- 未开发入口由占位页（PlaceholderPage）承接；
- 平台模板库管理页编辑表单不含 periods（新建模板默认视为不限周期，过滤时始终显示）；periods 由代码侧维护；
- 库与场景解耦：新增场景只需在标准库/模板库注册条目，智能体无需改代码（“标准即配置”）。
