# 术语与口径表

> 全局唯一口径定义；标书、Page Spec、代码三处对齐。**新增术语只在此登记**，页面文档引用不重复定义。

## 一、标注与实现度（全模块）

| 术语 | 定义 | 主要使用处 |
|---|---|---|
| 原型实现度 | 功能点在原型阶段的实现程度：已实现（可交互、逻辑真实）/ 演示数据（预置数据走流程）/ 待开发（原型界面未实现，开发阶段实现）；**不代表范围裁剪** | 全部页面 |
| 已实现 | 页面可交互且业务链路真实贯通 | 全部页面 |
| 演示数据 | 页面可交互，以预置数据走通流程；真实逻辑在开发阶段实现 | 全部页面 |
| 待开发 | 原型界面未实现、开发阶段实现的功能点 | 全部页面 |

## 二、架构与规则调度（全模块）

| 术语 | 定义 | 主要使用处 |
|---|---|---|
| 公域规则库 | 平台侧权威规则与配置资产（政策标准库、排放因子库、核算公式库、单元过程库、平台模板库、Skill 管理） | 运维管理 / 智能体中心 |
| 私域台账库 | 企业侧数据资产（组织资源库、企业因子库、佐证材料库、产品与物料库、SOP 库、改善措施库、报告与档案中心） | 组织资源 / 智能体中心 |
| 标准即配置 | 标准解析为结构化配置包后驱动全流程；新标准仅需入库配置模板，无需改代码 | 零碳工厂 / 智慧报告 / 各核算线 |
| 库与场景解耦 | 业务场景只消费库、不维护规则本体；新增场景只需在库中注册条目 | 全模块 |
| 版本锁定（模板漂移） | 任务创建时快照锁定标准与模板版本，库升版不回溯改写在途任务；可复现“当时依据的是哪一版” | 智慧报告 / 零碳工厂 |
| 确定性边界（LLM 不算数） | 数值计算全部由确定性引擎执行，大模型只做理解、解释与文本生成，不参与算数 | 全模块 |
| 内容指纹 | 归档/交付时对全文序列化计算 SHA-256 指纹，用于防篡改校验 | 智慧报告 / 零碳工厂 |
| 证据链（穿透） | 从报告/材料中的数值反向追溯到底层原始凭证的链路（报表四级 / 核算七级，见下） | 全模块 |

## 三、智慧报告（法定报送）

| 术语 | 定义 | 主要使用处 |
|---|---|---|
| 期次 | 报送计划的一个周期单位（月度/季度/半年度/年度） | 智慧报告 |
| 提报窗口 | 期次允许提报的日期区间（起止日） | 智慧报告 |
| 期次派生 | 生成日（nextGen）已到且期次任务不存在时，自动创建期次任务 | 智慧报告 R-06 |
| 提前启动 | 对未到期计划手动实例化下期草稿任务 | 智慧报告 R-07 |
| 在途防重（earlyKey） | 以计划 id 为去重键，防止自动派生与提前启动重复建单 | 智慧报告 R-06/R-07 |
| 口径适配 | 按报送部门规则转换指标名 / 范围 / 计算口径 / 粒度（四类转换） | 智慧报告 |
| 预填 | 按报告类型映射自动填充表单字段（模板 prefill → 大模型 → 留空手填，三级策略） | 智慧报告 |
| 四级溯源 | L1 报表 → L2 口径适配 → L3 模块数据池 → L4 原始采集；原「L3 标准化级」已移除（无独立数据源，语义并入 L2），取不到数据时如实标注「本层无记录」、不用演示值兜底 | 智慧报告 |
| 存证底卷 | 已归档/已提报/已受理任务的只读凭证直读入口（官方回执凭单 + 法定数字指纹存证） | 智慧报告 R-13 |
| 三级审核 | 填报人自查 → 部门负责人审核 → 碳管理师复核；全部通过后方可签字归档 | 智慧报告 |
| 单人极速签发（DIRECT_SIGN） | 单人闭环签发基线（默认，操作人元数据留痕） | 智慧报告 |
| 多级协同审批（MULTI_LEVEL） | 多节点审批链（3 节点链） | 智慧报告 |
| 登记提报 / 登记受理 | 归档后人工登记对外提报与主管部门受理回执（无 API 时以人工录入为准） | 智慧报告 R-04 |
| 审批层级 | 创建任务时确定的审批级数：**0 无需审批**（填报人确认即签发归档）/ 1 一级 / 2 二级 / 3 三级，多级时按平台三级审核链（填报人自查 → 部门负责人审核 → 碳管理师复核）取前 N 级；编排内只读执行 | 智慧报告 |
| 任务级审批配置 | 任务对象上的审批层级与审核节点 / 审核人（approval.level + chain），创建时锁定、编排内只读；平台无流程引擎，以「任务级配置快照 + 节点状态机」替代，接入 BPMN 时交出 chain 即可 | 智慧报告 |
| 提报状态 | 报送任务的三态推进（已归档·待提报 → 已提报 → 已受理），由人工登记驱动；部门 × 期次提报看板已下线，状态统一由报告列表表达 | 智慧报告 |

## 四、碳核算与评价申报

| 术语 | 定义 | 主要使用处 |
|---|---|---|
| 七级溯源 | 核算全过程的证据链层级 | 碳核算 |
| 范围一/二/三 | 温室气体排放范围划分（直接 / 外购能源 / 其他间接） | 碳核算 |
| 两级判定 | 先判定指标达标性，再综合判定星级 / 零碳水平 | 零碳工厂 |
| 核心指标 / 引导指标 | 零碳工厂指标体系两类：核心指标含基本要求与目标要求两级口径；引导指标为过程脱碳、协同降碳、智能控碳、碳抵销、信息披露等 | 零碳工厂 |
| 六阶段申报流 | 标准规则适配 → 核算模型搭建 → 数据收集与校验 → 指标核算与评价 → 建设目标与优化建议 → 材料编制与数据溯源 | 零碳工厂 |
| 四道关键确认 | 资格确认① / 模型确认② / 结果确认③ / 材料确认④（企业把关节点） | 零碳工厂 |
| 两类指标 | 指标按“系统计算 / 企业填报”分类（计算类由确定性引擎完成，填报类由企业确认） | 零碳工厂 |
| 覆盖边界（材料包交付） | 零碳工厂智能体覆盖至申报材料包交付为止；官方评审、建设期管理与评估验收不在范围内 | 零碳工厂 |
| 申报主体两类 | 制造型企业 / 零碳算力设施（资格条件与适用指标不同） | 零碳工厂 |
