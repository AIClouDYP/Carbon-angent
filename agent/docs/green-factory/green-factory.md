# 绿色工厂自评价（/#/green-factory/agent）

> 模块：green-factory | 文件：accounting/agent.vue（主页面）、agentCoreMixin.js（数据与逻辑）、agentChatMixin.js（对话）、agent-scoped.css（样式）
> 对应标书：2.7.8 绿色工厂智能体 | 原型实现度：演示数据阶段（页面可交互，四阶段全链路走通，真实核算与后端配置在开发阶段接入）
> 评价标准：《绿色工厂评价通则》GB/T 36132-2025（2025-12-31 发布实施）
> 关联：绿色工厂为零碳工厂申报的前置条件（已入选国家绿色工厂名单），与零碳工厂共用同一套标准解析、核算引擎与证据链能力——见 [../zero-carbon-factory/](../zero-carbon-factory/)

## 1. 业务场景定位

面向创建绿色工厂的企业提供自评价辅助：按《绿色工厂评价通则》（GB/T 36132-2025）的评价指标体系开展资格核验、数据收集、指标核算与材料编制，输出标准格式评分表与建设方案。

- **面向谁**：企业能碳负责人 / 体系专员（自评执行）、企业分管领导（确认与签署）
- **解决什么问题**：14 项指标（含 5 项强度类）的核算与举证分散在质量、能源、环保、研发等部门；强度类指标需与行业引领值/基准值对标，口径与计算方法各异，非专业人员难以独立完成
- **业务目标**：把「评价标准 → 数据收集 → 指标核算 → 材料编制」转化为分步对话引导，企业在关键节点确认

## 4. 功能点详情

### G-01 智能体工作空间（首页）
- **位置**：`/#/green-factory/agent` 首页；左侧对话区 + 右侧历史自评侧栏
- **交互**：
  - 欢迎语展示 4 阶段流程（标准规则适配 → 数据收集与校验 → 指标核算与评价 → 材料编制与数据溯源）
  - 点击「开始自评」直接进入任务详情，无弹窗确认
  - 右侧「历史自评」展示进行中/已完成任务，点击可继续
- **边界**：首页仅承载入口与说明，不承载业务操作
- **数据**：欢迎语（4 阶段说明）、历史任务列表
- **验收**：[ ] 欢迎语为 4 阶段（非 5/6 阶段）；[ ] 点「开始自评」直接进入任务详情；[ ] 历史任务可点击进入

### G-02 ① 标准规则适配（作业区·四分组）
- **位置**：作业区阶段一，四个可折叠分组
- **交互**：
  - **企业信息**（默认收缩）：企业名称、统一社会信用代码、行业类别、规模、地址等，由组织资源库自动带出，可编辑
  - **产品信息**（默认展开）：产品清单（名称、计量单位、是否独立计量），支持增删；多产品自动推断口径
  - **评价标准**（默认展开）：评价标准（GB/T 36132-2025）、主体类型、评价年度（年份选择器，仅可选当前年及之前）
  - **自评资格**（默认收缩）：14 项资格条件（自动核验 + 人工确认），有待确认/不符项时标题显示提醒
- **边界**：资格不满足不阻断流程（核算后给出差距与改善路径）；产品清单为空时无法推进
- **数据**：企业信息（组织资源库）、产品清单（name / unit / metered）、评价标准与年度、资格核验结果（条件—现状—状态）
- **验收**：[ ] 四分组顺序与默认状态正确；[ ] 评价年度仅可选当前年及之前；[ ] 资格有待确认项时标题有提醒；[ ] 产品清单可增删且标注独立计量/分摊

### G-03 ② 数据收集与校验（作业区·指标清单）
- **位置**：作业区阶段二，按 5 个一级分类分组展示 14 项指标
- **交互**：
  - 每项指标可折叠，标题显示指标名、公式（hover 显示）、口径切换（强度类）、单位、待确认数
  - 参数表列：明细项 | 活动数据 | 因子 | 结果 | 数据源/佐证材料 | 状态
  - 数据源两类：**底座**（智能电表/流量计/MES/财务系统自动采集）、**材料**（检测报告/台账/合同等），各带 2 个操作按钮（选择/上传）
  - 状态三态：待补充（无值）→ 待确认（有值未核）→ 已确认（核对完成），点击标签切换
  - 顶部「下一项待处理」+ 底部「数据清单说明」快捷按钮
- **边界**：无值不能确认（提示先填数值）；底座数据可用材料替换（标记 overridden），支持恢复
- **数据**：14 项指标 × 各参数（活动数据 / 因子 / 数据源 / 状态 / 确认标记）
- **验收**：[ ] 14 项指标与 5 分类数量正确（4/4/3/2/1）；[ ] 参数表 6 列完整；[ ] 状态三态可切换；[ ] 底座/材料标签与按钮可用

### G-04 参数详情与引导联动（对话区）
- **位置**：单击参数行 → 左侧对话区推送；顶部「下一项待处理」按钮
- **交互**：
  - 单击任意参数行：左侧推送该参数详情（名称、所属指标、单位、当前值、因子、结果、数据源、状态）+ 4 项操作指引（修改数值/更换佐证/确认无误/继续下一项）
  - 「下一项待处理」：自动定位下一个未确认项并推送详情
  - 输入框、上传按钮点击不触发联动（阻止冒泡）
- **边界**：引导为只读说明，实际操作仍在右侧完成
- **数据**：参数详情（item / value / unit / factor / source / status）
- **验收**：[ ] 单击参数行左侧推送详情；[ ] 「下一项待处理」定位准确；[ ] 输入框点击不误触发

### G-05 强度指标双口径（作业区·指标标题）
- **位置**：5 项强度指标标题后（能源消耗强度、碳排放强度、原材料消耗强度、取水强度、主要污染物产生或排放强度）
- **交互**：
  - 切换控件：`[产品 | 产值]`
  - **产品**：按产品分组（独立计量产品 + 分摊产品），分母为各产品产量，单位如 tce/辆
  - **产值**：普通参数表，分母为工业总产值，单位如 tce/万元
  - 切换后参数表立即变形，两种口径数据源独立保留
- **边界**：口径为指标级设置（basis 字段），不影响其他指标
- **数据**：指标 basis（product / output）、两套参数（productItems / sharedItems / subs）
- **验收**：[ ] 5 项指标均有切换控件；[ ] 切换后产品分组与普通参数表互斥显示；[ ] 单位标签同步变化

### G-06 多产品分摊（作业区·分摊产品组）
- **位置**：产品口径下，分摊产品分组（独立计量产品之后）
- **交互**：
  - **共用计量项**：共用表读数只填一次（外购电力、天然气等），显示共用合计
  - **按产品分摊**：按产量比例自动分摊，展示产品 / 产量 / 数据源 / 分摊比例 / 分摊结果 / 单位产品值 / 状态
  - 产量可编辑，分摊比例实时重算
- **边界**：分摊之和 = 共用总量（校验通过）；分摊比例按产量计算，不支持手工调整
- **数据**：sharedItems（共用计量项）、productOutputs（各产品产量）
- **验收**：[ ] 共用项只填一次；[ ] 分摊比例 = 产量占比；[ ] 各产品分摊之和 = 共用合计

### G-07 ③ 指标核算与评价（作业区·核算结果）
- **位置**：作业区阶段三
- **交互**：
  - 展示 14 项指标：序号、名称、指标类型、单位、指标值、引领值、基准值、权重分值、得分、状态、计算说明、评分规则
  - 对标赋分：逆向指标（值 ≤ 引领值满分、≥ 基准值零分、区间线性）；正向指标反向；定性指标已开展满分
  - 顶部显示综合得分（满分 100）
- **边界**：指标值由确定性逻辑计算（AI 不参与算数）；演示阶段引领值/基准值为示例值
- **数据**：indicators[]（no / name / value / unit / leading / baseline / weight / score / status / detail / rule）
- **验收**：[ ] 14 项指标齐备；[ ] 得分按对标规则计算；[ ] 综合得分 = 各项得分之和

### G-08 ④ 材料编制与数据溯源（作业区 + 报告弹窗）
- **位置**：作业区阶段四（材料生成 + 数据溯源）；点「查看全文」打开方案弹窗
- **交互**：
  - 方案弹窗：左侧目录 7 章，右侧正文可编辑
  - 章节：基本信息表 / 一、概况 / 二、建设基础（含**标准格式评分表**）/ 三、建设目标分析 / 四、建设路径 / 五、预期成效 / 六、证明材料目录
  - **评分表**按 GB/T 36132-2025 表 C.1 格式：一级指标（权重）| 序号 | 二级指标 | 指标类型 | 单位 | 引领值 | 基准值 | 权重分值 | 得分 | 评分规则，末行合计
  - 数据溯源：四级证据链（指标 → 参数 → 来源 → 凭证）
- **边界**：正文含【待企业补充】占位符；数字部分需与核算结果一致
- **数据**：sections[]（title / blocks[]）、scoreTable、evidenceChain[]
- **验收**：[ ] 7 章齐备；[ ] 评分表 10 列 + 合计行；[ ] 证据链可追溯

### G-09 标准配置驱动（平台级共性架构）
- **位置**：非独立页面，贯穿阶段一至阶段三的数据来源
- **说明**：
  - 本平台 8 个业务场景（产品碳足迹、产品环境足迹、组织碳核算、北京碳市场、园区碳核算、零碳工厂、绿色工厂、报告提报）共用同一套标准配置驱动架构
  - 三层结构：**标准库**（指标体系 + 权重 + 公式引用）、**公式库**（表达式 + 变量 + 引用条款）、**因子库**（折标系数 / 排放因子 / 产污系数）
  - 绿色工厂加载 GB/T 36132-2025 配置包（14 项指标）
- **边界**：**当前为前端演示，三库以内置演示数据实现**（STANDARD_LIBRARY / FORMULA_LIBRARY / FACTOR_LIBRARY）；正式版须由后端配置服务加载
- **数据**：standardIndicators（14 项）、formulaOf(name)、factorOf(key)
- **验收**：[ ] 指标元信息与标准库一致；[ ] 公式可按指标名查询；[ ] 因子可按 key 查询

### G-10 会话管理
- **位置**：对话区顶部工具栏
- **交互**：新建对话（清空当前会话）、重置（恢复初始状态并保留项目）、返回（回到首页）
- **边界**：重置不清除已确认数据
- **数据**：messages[]、currentStepIndex、maxStepIndex
- **验收**：[ ] 三个按钮均可用；[ ] 重置后项目信息保留

## 5. 状态与口径

### 5.1 参数三态

| 状态 | 判定 | 颜色 |
|---|---|---|
| 待补充 | 无值或值为 — | 橙 |
| 待确认 | 有值但未确认 | 灰 |
| 已确认 | 有值且 confirmed = true | 绿 |

### 5.2 指标状态

| 状态 | 判定 | 说明 |
|---|---|---|
| met（达标）| 达到或优于引领值 | 满分 |
| improving（改进中）| 介于引领值与基准值之间 | 按线性赋分 |
| fail（未达标）| 未达到基准值 | 零分 |

### 5.3 强度口径

| 口径 | 分母 | 单位示例 | 适用 |
|---|---|---|---|
| 产品 | 各产品产量 | tce/辆 | 离散制造、需分产品核算 |
| 产值 | 工业总产值 | tce/万元 | 流程工业、多产品统一 |
