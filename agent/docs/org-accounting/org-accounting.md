## 1. 业务场景定位

面向园区入驻企业的碳管理人员，依据 **GHG Protocol 温室气体核算体系企业标准**（ISO 14064-1 可选补充），周期性产出企业碳排放核算结果与报告，支撑合规披露、碳市场数据报送与集团碳管理。

场景特点决定形态：**配置一次、长期周期运行**（月度核算、次月自动生成上月任务；年度由月度汇总派生）。界面采用**单页两用**——配置与运行都在工作台内完成，由**对话引导**串联。

**核心机制**：三步配置、四项确认，由对话逐项引导；未完成配置前不可查看结果数据。

## 4. 功能点详情

### O-01 配置引导与结果直达
- **交互**：
  - **无周期配置**（首次进入）：定位「配置与模型·①」，对话播报「三步·四项确认」清单（纯说明，无按钮），随即推送「确认主体信息」内容
  - **已有周期配置**：**直接进入「结果与数据」**展示当期核算结果，不重复配置引导
- **原型实现度说明**：当前原型**为演示配置流程**，进入场景时**强制清空周期配置**并回到 ①；**目标态**为"有配置直接出结果，仅无配置时走引导"。故本节「每次进入回到①」为演示取舍，不代表目标逻辑。
- **边界**：四步确认未完成时，点「结果与数据」被拦截并定位到待确认项。
- **数据**：`hasCycleConfig`（本地 `ghg_cycle_config_v2`）、`guideChecklist`（四确认项）、`infoConfirmed / sourceListConfirmed / standardConfirmed / modelConfirmed`。
- **验收**：[ ] 无配置时走引导、按严格顺序逐项推送；[ ] 未配置时结果页签不可进；[ ]（目标态）已有配置时直达结果页

### O-02 确认主体信息
- **交互**：从组织资源库带出企业名称/行业/核算频率/因子库，回复「确认主体信息」或点按钮确认；确认后推送「确认排放源清单」。
- **边界**：确认后右侧①基础信息标记「已确认」，仍留①（还有清单未确认）。
- **数据**：`orgInfo`、`factorDatabases`。
- **验收**：[ ] 企业信息自动带出；[ ] 确认后进度清单 ✅、右侧标记同步。

### O-03 确认排放源清单
- **交互**：清单 = **资源台账抽象**（设备设施 → 对应排放源，`org_resources_v3`）+ **智能体侧清单**（手工新增 / 上传识别补录，`agent_sources_v1`，标注"手工新增"，不写台账）。支持新增/修改/停用/删除（台账条目与侧清单条目分别处理）；提供「上传台账识别」——上传「能源消耗台账 / 能碳数据采集清单」由智能体识别补录（覆盖：只到能源品种无具体设备的排放源、范围三项如员工通勤/运营废弃物）。每次变更对话同步说明；回复「确认排放源清单」确认并跳②。
- **概念口径**：资源台账记**实体资源**（设备设施，能源品种挂其下）；**排放源/排放单元**是碳排放计算中的抽象概念，①清单是二者的映射与补充，不回写台账。
- **边界**：清单与③核算模型同源；缺漏可通过「资源台账新增」或「上传台账识别」补充。
- **数据**：`emissionSourceList`、`org_resources_v3`。
- **验收**：[ ] 清单增删改即时写回资源台账；[ ] 变更时对话同步说明；[ ] 确认后右侧跳②。

### O-04 确认核算标准
- **交互**：从标准库加载标准（GHG Protocol 为主、ISO 14064-1 补充），选定后 `applyStandardBoundary()` 重建边界（范围一/二/三、组织边界、基准年）；回复「确认核算标准」确认并跳③。
- **边界**：边界项为标准口径全列，不可删改；版本/发布年份从标准库带出。
- **数据**：`standards`、`selectedStandard`、`boundaryConfig`、`configuredStandardVersion`。
- **验收**：[ ] 标准切换触发边界重建；[ ] 版本/年份从库带出；[ ] 确认后右侧跳③。

### O-05 确认核算模型
- **交互**：①清单×②边界自动匹配生成（排放源/排放单元/公式/计算参数，只读）；回复「确认核算模型」完成四步。
- **边界**：模型只读；确认后推送「四项全部完成」，可启用周期核算。
- **数据**：`emissionModel`、`guideAccountingModel`。
- **验收**：[ ] 模型自动匹配且只读；[ ] 确认后四项全 ✅。

### O-06 启用周期核算
- **交互**：点击「启用周期核算」→ 四段式叙事（识别/依据/执行/结果，默认折叠）→ 自动跳「结果与数据」→ 播报当期结果摘要。
- **数据**：`currentCycle`、`pageMode`。
- **验收**：[ ] 启用后自动跳结果页；[ ] 播报当期摘要（总量/范围构成/环比同比/完整度/解读）。

### O-07 双向联动
- **交互**：watch 监听 `cdActiveTab / resultTab / resultPeriod / resultGranularity / resultYear / resultYearMonth / cfgActive`，切换时对话播报当期内容；对话指令驱动时主动播报。
- **边界**：`_silentSwitch` 抑制对话驱动的重复播报；150ms 去抖合并同批状态变化。
- **数据**：`_silentSwitch`、`_syncTimer`、`buildSyncMessage(kind)`。
- **验收**：[ ] 右侧切换→对话同步；[ ] 对话切换→不重复播报；[ ] 切换切年只播报一次。

### O-08 结果与数据（月度）
- **交互**：KPI（总量/完整度/同比/环比，缺项提示归完整度卡）；趋势（分项堆叠柱+参照折线）；范围构成（环形图+表：项目/占比/数值/同比/环比变化）；贡献；数据清单（组→子项卡片→3 列参数表+计算式块）；点击卡片/参数打开溯源抽屉。
- **数据清单结构**：组头（范围 · N 项 · 排放量）可折叠；子项卡片含「参数名称 / 参数值（数值右对齐等宽 + 单位浅色）/ 来源 · 佐证材料」三列，参数按计算式顺序编号（1 活动数据、2 排放因子、3+ 折算参数），卡片底部为计算式块（公式 = 结果），默认展开、可逐项折叠。
- **边界**：缺失项按 0 计入并提示；溯源抽屉为「上参数 / 下详情」两段式（详见 O-14）。
- **数据**：`resultTotals`、`resultMissingItems`、`resultTrendYear`、`resultScopeTable`。
- **验收**：[ ] 四卡顺序为总量/完整度/同比/环比；[ ] 缺项提示在完整度卡；[ ] 数据清单可点开溯源抽屉。

### O-09 年度视图
- **交互**：粒度切换「月/年」；年度总量/范围构成/完整度由月度汇总派生（不重算）；数据清单按月页签；趋势近 5 年；构成表隐藏环比列。
- **边界**：年度锁定为纯派生（12 个月全锁定→年度自动锁定）。
- **数据**：`resultGranularity`、`resultYearMonths`、`resultYearTotals`、`resultYearMonth`。
- **验收**：[ ] 年度数据=月度汇总；[ ] 月份页签切换；[ ] 趋势近 5 年。

### O-10 数据质量与缺失补充
- **交互**：完整度独立 KPI 卡显示「缺 N 项/N 个月」；结果摘要列出缺失明细；「补充缺失数据」按钮进入补充（上传凭证/按建议值补录）。
- **数据**：`resultCompleteness`、`resultMissingCount`、`resultMissingItems`。
- **验收**：[ ] 缺失项有提示与补充入口；[ ] 演示数据保留一项缺失（运营废弃物）。

### O-11 核查对接
- **交互**：结果引导语下方「推荐核查机构」按钮，点击后对话内返回名单（名称/所在地/资质/核查范围/评级报价/联系方式）。
- **边界**：模拟接口延迟 900ms（typing 态）；名单来自核查机构库。
- **数据**：`verificationOrgs`。
- **验收**：[ ] 按钮存在；[ ] 点击后返回 5 家机构名单。

### O-12 锁定 / 导出 / 报告
- **交互**：悬浮操作栏（仅数据清单页签）三按钮：锁定数据 / 导出数据 / 生成报告。
- **边界**：锁定后不可修改，可解除。
- **数据**：`isPeriodFiled` / `currentCycle`。
- **验收**：[ ] 三按钮可用；[ ] 锁定状态在顶部「数据状态」展示。

### O-13 历史对话栏

- **数据**：`conversationHistory`。
- **验收**：[ ] 会话记录、切换、删除、收缩正常。

### O-14 数据清单与参数溯源抽屉

- **交互**：清单按「范围 → 排放单元 → 参数表」组织；子项卡片整卡可点，打开右侧溯源抽屉。
- **抽屉结构（两段式）**：
  - 上段「计算参数」：单列表，每行 `符号（AD/EF/P2…）+ 参数名称 + 参数值 + ✏️`；行可点击选中（浅蓝底 + 左侧蓝条），符号配色区分类型（AD 蓝 / EF 绿 / 折算参数灰）。
  - 下段随选中参数切换三段：**凭证材料**（📎 凭证号 + 已归档标签 + 来源 + 查看/下载；因子类显示“因子库/折算参数无需凭证材料”）、**匹配过程**（候选数徽章 + 取数规则 + 采用项）、**更正记录**（该参数的更正历史）。
- **边界**：活动数据匹配为“台账/测点唯一命中”；因子按“企业实测 > 省级清单 > 国家缺省，同级取年份最新、地域最精确”取数。
- **数据**：`traceRow`、`activeParam`、`paramMatchInfo()`、`paramEditLog`。
- **验收**：`[x]` 参数行可选中并联动下段；`[x]` 符号与计算式变量一致；`[x]` 三段内容随参数切换。

### O-15 参数更正与留痕

- **交互**：抽屉参数行 ✏️ → 弹窗（参数名称只读 / 原值只读 / 新值必填 / 更正理由必填 / 佐证附件：显示现有凭证 + 上传附件）→ 保存更正。
- **规则**：更正写入 `emissionModel` 源值，`resultRows/resultGroups` 自动重算；留痕记入 `paramEditLog`（时间 / 参数名 / 原值 → 新值 / 理由），在该参数「记录」页展示；本期锁定后 ✏️ 隐藏且方法拦截。
- **数据**：`openParamEdit()`、`saveParamEdit()`、`_findEmissionItem()`、`paramEditLog`。
- **验收**：`[x]` 更正后数值与汇总同步变化；`[x]` 记录页出现留痕；`[x]` 锁期不可更正。
