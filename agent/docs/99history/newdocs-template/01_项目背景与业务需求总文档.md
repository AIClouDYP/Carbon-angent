## 一、 项目背景与政策依据

### 1.1 宏观战略与政策法规背景
> *【编写指引】简要阐述国家/行业层面的顶层战略与法规依据，奠定项目立项的合规性与前瞻性。*
* **国家顶层战略**：如国家“碳达峰、碳中和”战略、从“能耗双控向碳排放双控转变”的制度改革要求。
* **部委与行业法规**：如生态环境部《企业温室气体排放核算方法与报告指南》、国家统计局能源统计制度、工信部绿色制造体系建设指南等。
* **地方与区域监管要求**：省市级低碳试点、重点用能单位节能降碳监管考核指标。

### 1.2 建设主体业务现状与挑战
> *【编写指引】客观分析企业/园区/单位当前的业务痛点与技术瓶颈，说明“为什么非建不可”。*
* **现状描述**：现有信息化系统分散，涉及生产、设备、财务、安环等多个孤岛，能耗与碳排数据靠人工台账或邮件收发。
* **面临瓶颈**：
  1. **数据归集难**：底层表计数据、发票凭据缺乏统一线上汇聚渠道；
  2. **跨部门口径冲突**：面对发改、统计、生态环境等多头监管，数据折算标准不一，极易发生“数出多门、部门打架”；
  3. **审计与合规风险**：核算过程缺乏数据血缘链，面对第三方核查或监管抽检时无法快速自证清白。

### 1.3 立项必要性与紧迫性
* 顺应强监管趋势，防范行政处罚与合规通报风险；
* 赋能绿色供应链与出口产品竞争力（如应对欧盟 CBAM / PEF 等绿色贸易壁垒）；
* 推动节能降碳技术改造，释放节能降耗经济效益。

## 二、 目标受众与核心需求分析

### 2.1 目标用户角色画像
| 角色分类 | 代表岗位 / 主体 | 核心关注点 | 在系统中的主要行为 |
|:---|:---|:---|:---|
| **基层操作人员** | 现场仪表抄表员、统计员、填报人 | 填报效率、不要重复录入、容错提示 | 数据上传、表格补录、工况异常初报 |
| **企业管理人员** | 能源管理师、碳资产负责人、厂长 | 合规审核、减排潜力、履约成本控制 | 数据复核、三级签发、降碳路径决策 |
| **园区监管机构** | 园区管委会经发局/环保局人员 | 辖区总览、企业横向对比、超标预警 | 园区宏观大屏监控、企业报送督办催办 |
| **外部审计/监管** | 第三方核查机构、政府主管部门 | 数据真实性、防篡改、计算依据透明度 | 报告通读、溯源穿透、回执发放与受理 |

### 2.2 核心业务痛点与诉求拆解
* **痛点 1（一数多报与口径转换繁重）**：同一份底数，报送不同部门要求不同折算规则，依赖人工翻查规范，效率低且易算错。
  * *对应诉求*：底层通用数据一次采集，各报送任务依据法定规范锁定单一确定口径，系统自动完成折标与排放核算。
* **痛点 2（大模型幻觉与严肃合规的矛盾）**：通用 AI 助手容易在核心算式上产生幻觉算错数字，无法通过严肃审计。
  * *对应诉求*：严格执行规则引擎与 AI 润色解耦，物理公式运算只读固化，AI 仅受控优化文字表述。
* **痛点 3（数字断层不可审计）**：生成的报表数值无法向后追溯到底层真实依据。
  * *对应诉求*：报告中每一个数据均可穿透回溯至最原始的物理电表、流量计、ERP发票或MES产量。

## 三、 总体建设目标与业务蓝图

### 3.1 建设总体目标
* **定性目标**：打造“标准内置、过程留痕、受控智能、全链穿透”的企业/园区级智慧能碳数字化管控中枢。
* **量化目标**：
  * 周期性报送数据填报与汇总效率提升 80% 以上；
  * 主管部门报送材料一次性合规通过率达到 99% 以上；
  * 关键排放数据 100% 具备底层表计/发票溯源凭证链。

### 3.2 平台总体业务架构蓝图
```
┌────────────────────────────────────────────────────────┐
│ 1. 展现交互层：智能助手「小易」对话交互 + 专家工作台向导     │
├────────────────────────────────────────────────────────┤
│ 2. 场景应用层：核算类场景 + 评价申报类场景 + 周期性报送中枢   │
├────────────────────────────────────────────────────────┤
│ 3. 共享引擎层：因子匹配引擎 + 规则核算引擎 + 溯源穿透 + 导出签发│
├────────────────────────────────────────────────────────┤
│ 4. 支撑数据层：通用基础数据底座 + 企业私域台账 + 平台公域规则库 │

```

### 3.3 预期交付效益
* **管理效益**：理顺多部门报送机制，权责留痕可查；
* **合规效益**：规避数据造假与计算失误带来的监管通报风险；
* **经济效益**：精准定位高能耗高碳排节点，支撑精准技改投资。
