## 一、文档概述

### 1.1 编写目的

本文档将BRD中定义的业务需求转化为可执行的功能需求，明确每个功能模块的输入、输出、触发条件、预期行为和验收条件，供开发和测试团队直接参考。

### 1.2 功能架构总览

碳足迹智能体的功能模块按九阶段核算流程组织，加上智能体入口和公共支撑模块，共计11个功能域：

```
┌────────────────────────────────────────────────────────────┐
│                    智能体入口层                              │
│  [F-A01] 工作台  [F-A02] 应用中心  [F-A03] 碳足迹智能体中心 │
├────────────────────────────────────────────────────────────┤
│                    九阶段核算流程层                          │
│  [F-S1] 目标与范围  [F-S2] 功能单位  [F-S3] 系统边界        │
│  [F-S4] 数据采集    [F-S5] 因子匹配  [F-S6] 数据校验        │
│  [F-S7] 碳足迹计算  [F-S8] 结果解释  [F-S9] 报告生成        │
├────────────────────────────────────────────────────────────┤
│                    公共支撑层                                │
│  [F-C01] 产品模型库  [F-C02] 排放因子库  [F-C03] 溯源引擎    │
│  [F-C04] AI对话引擎  [F-C05] 权限控制    [F-C06] 操作审计    │
└────────────────────────────────────────────────────────────┘
```

## 二、智能体入口层

### F-A01 智能体工作台

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-A01 |
| 功能名称 | 智能体工作台 |
| 优先级 | P0 |
| 对应页面 | `agent-center/views/Workspace.vue` |
| 路由 | `/agent-center/workspace` |

**功能描述**：碳亦管碳核算平台的统一入口，展示本期2个碳核算智能体（产品碳足迹+组织碳核算）的运行状态、当日任务统计和最近核算任务列表。

**输入**：
- 用户登录后的身份信息（角色、组织）
- 各智能体的运行状态数据

**输出**：
- 统计卡片（智能体总数/运行中任务/待处理任务/异常告警）
- 智能体应用列表（2个智能体卡片：产品碳足迹智能体 + 组织碳核算智能体，含名称/描述/状态标签）
- 最近核算任务表格（任务名称/产品/状态/进度）

**触发条件**：用户登录后默认重定向到此页面

**预期行为**：
1. 页面顶部4张统计卡片实时刷新
2. 2个智能体卡片（产品碳足迹智能体 + 组织碳核算智能体）按1行2列排列，点击进入对应智能体详情
3. 点击"产品碳足迹核算智能体"卡片 → 跳转到 F-A03
4. 最近任务表格支持按状态筛选和关键字搜索
5. 任务行点击 → 跳转到对应的核算工作台(F-S4)

## 三、九阶段核算流程层

### F-S1 目标与范围定义（Stage 1）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S1 |
| 功能名称 | 目标与范围定义 |
| 优先级 | P0 |
| 对应页面 | `agent.vue` (Step 1 对话流程) |

**功能描述**：AI引导用户明确核算目标和适用标准，自动识别产品类别并推荐核算标准组合。

**输入**：
- 产品名称和型号（任务创建时已输入）
- 组织边界（企业级/产线级/工厂级）
- 核算周期起止日期

**输出**：
- 核算目标描述文本
- 推荐的核算标准组合（ISO 14067 + GB/T 24067 默认，可选PAS 2050/EPD）
- 产品类别识别结果（新能源产品/建材/纺织/农产品等）

**触发条件**：新创建的核算任务首次进入智能体对话

**预期行为**：
1. AI根据产品名称自动识别产品类别（匹配产品模型库）
2. 推荐最适合的核算标准组合，用户可增减标准
3. 用户确认后 → 自动推进到Stage 2

---

### F-S2 功能单位与基准设定（Stage 2）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S2 |
| 功能名称 | 功能单位与基准设定 |
| 优先级 | P0 |

**功能描述**：确定产品的功能单位（如"1辆汽车""1kWh电池""1吨水泥"）和基准流。

**输入**：
- 产品类别（Stage 1已确定）
- AI推荐的功能单位选项列表

**输出**：
- 功能单位定义（含数量、单位、质量规格描述）
- 参考流声明

**触发条件**：Stage 1确认完成

**预期行为**：
1. AI根据产品类别推荐3~5个常用功能单位选项
2. 用户选择或自定义功能单位
3. AI校验功能单位是否满足ISO 14067要求（必须可量化、可比较）

### F-S3 系统边界划定（Stage 3）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S3 |
| 功能名称 | 系统边界划定 |
| 优先级 | P0 |

**功能描述**：确定哪些生命周期阶段纳入核算范围，用户可调整"是否含XX阶段"。

**输入**：
- AI生成的系统边界草案（根据产品类别自动推荐）
- 用户对各阶段的含/不含选择

**输出**：
- 系统边界定义（含生命周期阶段列表：原材料获取/生产制造/仓储物流/使用阶段/废弃回收）
- 边界可视化预览图
- 截断规则声明（占比<1%截断，累计<5%）

**触发条件**：Stage 2确认完成

**预期行为**：
1. AI根据产品类别推荐默认边界（如汽车默认Cradle-to-Gate+使用+废弃，建材默认Cradle-to-Gate）
2. 用户可勾选/取消各阶段（"是否含使用阶段""是否含废弃回收"等）
3. 系统边界子步骤分为5步：边界类型选择→阶段勾选→截断规则设定→分配规则选择→边界锁定确认
4. 边界锁定后 → 任务状态从CREATED转为DATA_COLLECTING

### F-S4 数据采集（Stage 4）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S4 |
| 功能名称 | 活动数据采集 |
| 优先级 | P0 |
| 对应页面 | `data-collection.vue` + `agent.vue` Step 4对话 |

**功能描述**：采集每个排放源的活动数据，支持手工填报、Excel批量导入、IoT自动拉取、ERP/MES同步、供应商问卷回收5种数据来源。

**输入**：
- 排放源清单（由产品模型+系统边界自动生成）
- 各数据来源的活动数据值

**输出**：
- 已填写的排放源数据表（每个排放源含：活动数据值/单位/数据来源/采集方式/采集时间）
- 采集进度概览（总数/已填写/部分填写/未填写）
- 数据校验状态（"有N项需修正"按钮）

**触发条件**：
- 任务状态进入DATA_COLLECTING
- 用户点击任务进入数据采集页
- 用户在AI对话中发出填报指令

**预期行为**：

**子功能F-S4-1：排放源分组展示**
1. 排放源按生命周期阶段分组（原材料/生产制造/仓储物流/使用废弃）
2. 每组显示填写率进度条
3. 支持分类视图和全局表格视图切换

**子功能F-S4-2：逐项填报**
1. 每个排放源展示为可编辑卡片/表格行
2. 填写字段：活动数据值、单位（下拉选择）、数据来源类型（下拉）、采集说明
3. 填写后实时更新进度概览
4. 自动保存，无需手动提交

**子功能F-S4-3：Excel批量导入**
1. 下载Excel模板（8个Sheet：使用说明/基本信息/BOM/制造/运输/安装/生命末期/DQR）
2. 上传已填写的Excel → 解析导入 → 自动匹配排放源
3. 导入结果报告：成功N条/跳过N条/错误N条
4. 支持增量导入（不覆盖已有数据）

**子功能F-S4-4：IoT自动拉取**
1. 配置IoT仪表映射（仪表ID → 排放源ID）
2. 定时拉取（每15分钟/每小时/每日聚合）
3. 显示月度用电量分时曲线（峰/谷/平）
4. 标注数据来源为"IoT自动采集"

**子功能F-S4-5：ERP/MES同步**
1. 配置ERP字段映射（物料编码→BOM项、生产订单号→工序）
2. 一键同步拉取BOM数据和能耗分项计量数据
3. 标注数据来源为"ERP同步"

**子功能F-S4-6：供应商问卷回收**
1. AI自动生成供应链碳数据调查问卷
2. 通过供应商门户发送问卷
3. 回收后自动填入上游排放源活动数据
4. 标注数据来源为"供应商问卷"

**子功能F-S4-7：数据校验快速检查**
1. 顶部"数据校验"按钮 → 执行格式校验（单位合法性/数值范围/必填项）
2. 标记有问题的排放源行（黄色/红色边框）
3. 全部通过后 → "提交并进入下一步"按钮激活

### F-S5 排放因子匹配（Stage 5）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S5 |
| 功能名称 | 排放因子匹配 |
| 优先级 | P0 |

**功能描述**：为每个排放源自动匹配最合适的排放因子，标注匹配置信度，支持人工确认/更换因子。

**输入**：
- 已填写活动数据的排放源清单
- 排放因子库数据

**输出**：
- 已匹配的排放源清单（每项新增：因子值/因子单位/因子来源/因子版本/匹配置信度/DQR五维度评分）
- 匹配概览（自动匹配N项/需人工确认N项/未匹配N项）

**触发条件**：Stage 4数据采集提交后自动触发

**预期行为**：
1. AI按以下规则自动匹配因子：
   - 活动数据单位 → 因子单位一致性匹配
   - 组织地理位置 → 电网区域因子匹配
   - 工艺类型 → 技术代表性匹配
   - 核算年份 → 因子时效性匹配
2. 置信度≥85%的匹配项自动锁定，≤85%的弹出确认卡片
3. 每个因子显示：因子值、版本号、发布方、有效日期、替代因子列表
4. 用户可手动更换因子（选择替代因子或自定义因子）
5. 因子匹配完成后 → 自动进入Stage 6数据校验

### F-S6 数据校验（Stage 6）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S6 |
| 功能名称 | 数据校验 |
| 优先级 | P0 |
| 对应页面 | `governance.vue` |
| 校验规则文档 | 阶段6-数据校验规则详解 v2.1 |

**功能描述**：执行四项串行阻断式数据校验（完整性→一致性→趋势→DQR），发现的异常以卡片形式呈现，所有卡片处理为「已处理」后放行进入Stage 7。

**输入**：
- 已匹配的排放源数据集（含活动数据+排放因子+DQR评分）

**输出**：
- 三级校验摘要（L1格式/L2完整性/L3一致性 + 评分环形图）
- 异常卡片列表（每张卡片含：异常ID/严重程度颜色/异常描述/处理选项按钮组）
- 校验状态：通过/阻断

**触发条件**：任务状态进入GOVERNANCE

**预期行为**：

**子功能F-S6-1：完整性校验（C-01~C-06）**
1. 检查必填流缺失(C-01)、主要能耗缺失(C-02)、核心物料缺失(C-03)、废弃物缺失(C-04)、末端阶段缺失(C-05)、关键排放贡献项缺失(C-06)
2. 🔴类异常：弹出阻断卡片，必须补充数据
3. 🟡类异常(C-04)：弹出提示卡片，确认即可

**子功能F-S6-2：一致性校验（S-01~S-06）**
1. 检查分配比例偏差(S-01)、单位不一致(S-02)、物料传递量不一致(S-03)、因子年份不匹配(S-04)、功能单位不一致(S-05)、截断项未说明(S-06)
2. 气体单位不一致(S-02)：弹出参考状态确认卡片（Nm³/Sm³/m³选择）
3. 🔴/🟠/🟡按严重程度分级处理

**子功能F-S6-3：趋势校验（T-01~T-06）**
1. 检查历史均值偏差(T-01)、能耗同比异常(T-02)、因子时效性(T-03)、回收率偏离(T-04)、逻辑一致性(T-05)、产量用量比例(T-06)
2. 偏差自动分级：≤阈值一半→✅自动通过；0.5~1倍→🟡需说明；1~2倍→🟠需核实；>2倍→🔴阻断

**子功能F-S6-4：DQR校验（D-F-01~D-F-06 + D-A-01~D-A-06）**
1. 排放因子轨：因子综合DQR超限(D-F-01)、单维度超限(D-F-02)、地理代表性(D-F-03)、时间相关性(D-F-04)、技术代表性(D-F-05)、来源标注(D-F-06)
2. 活动数据轨：活动数据综合DQR超限(D-A-01)、可靠性(D-A-02)、时间覆盖(D-A-03)、地理代表性(D-A-04)、技术代表性(D-A-05)、来源标注(D-A-06)
3. 双轨分别评分、分别校验，两轨均须通过

**子功能F-S6-5：异常卡片处理**
1. 每张卡片提供6种处理方式按钮组：
   - 补充数据（🔴缺失类）
   - 确认使用（🟠偏差类）
   - 确认正常（🟡提示类）
   - 接受评分（🟠DQR类）
   - 更新因子（🟡因子过旧类）
   - 忽略（🟡纯提示类，需填写原因）
2. 处理后卡片状态从PENDING→RESOLVED
3. 支持"批量处理同类异常"
4. 全部卡片RESOLVED → 自动推进到Stage 7

**子功能F-S6-6：综合质量评分**
1. 显示SVG环形评分图（总分/100）
2. 三级校验进度条（L1/L2/L3各显示通过/警告/失败段）
3. 评分判定：<60不合格/60~75合格/76~90良好/90+优秀

### F-S7 碳足迹计算（Stage 7）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S7 |
| 功能名称 | 碳足迹计算 |
| 优先级 | P0 |

**功能描述**：对校验通过的排放源数据逐源计算碳排放量，按范围(Scope1/2/3)和生命周期阶段汇总。

**输入**：
- 校验通过的排放源数据集

**输出**：
- 逐源计算结果（每项：emission = value × factor）
- 碳足迹总量（kgCO2e）
- 范围分解（Scope1直接排放/Scope2能源间接/Scope3其他间接）
- 阶段分解（原材料/制造/运输/使用/废弃）
- 不确定度范围（±%）

**触发条件**：Stage 6全部校验通过后自动触发

**预期行为**：
1. 计算耗时≤30秒
2. 计算完成后自动推进到Stage 8
3. 计算失败 → 任务状态转FAILED，显示错误日志

### F-S8 结果解释（Stage 8）

| 属性 | 值 |
| --- | --- |
| 功能编号 | F-S8 |
| 功能名称 | 结果解释与热点分析 |
