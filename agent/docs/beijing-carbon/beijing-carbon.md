## 1. 业务场景定位

面向纳入北京市碳排放权交易管理的**重点排放单位**，按**北京市地方标准**完成碳排放核算、报告与核查对接，支撑年度配额履约。

**法规与标准依据**：
- 地方标准：**DB11/T 1781~1787-2020《二氧化碳排放核算和报告要求》系列（7 项，按行业分册）**，默认「DB11/T 1787-2020 其他行业」（汽车制造归入此类）
- 法规：北京市碳排放权交易管理办法
- 配套：北京市主管部门指定排放因子

**与组织碳核算的关键差异**（共享引擎、场景独立）：

| 维度 | 组织碳核算 | 北京碳市场 |
|---|---|---|
| 标准 | GHG Protocol / ISO 14064-1 | DB11/T 1781~1787-2020（7 项分册）|
| 口径 | 范围一 / 二 / 三 | **直接排放 / 间接排放** |
| 细分项 | 按 GHG 类别 | 化石燃料燃烧 / 工业生产过程 / 消耗外购电力 / 消耗外购热力 |
| 对比基准 | 基准年 | **上年** |
| 因子来源 | IPCC / 国家因子库 | **北京市主管部门指定因子** |
| 对象 | 企业 | **重点排放单位** |
| 特色能力 | — | **核查对接（推荐核查机构）** |

## 4. 功能点详情

### B-01 配置引导与结果直达
- **交互**：
  - **无周期配置**（首次进入）：固定 `selectedStandard = DB11/T 1787-2020`、清空 `boundaryConfig.baseYear`（北京不用基准年），回到「配置与模型·①」，走配置引导
  - **已有周期配置**：**直接进入「结果与数据」**展示当期核算结果
- **原型实现度说明**：当前原型**为演示配置流程**，进入场景时**强制清空周期配置**并回到 ①；**目标态**为"有配置直接出结果，仅无配置时走引导"。
- **边界**：可选标准只含 7 项 BJ 地方标准（`loadBjStandardsFromLibrary()` 过滤掉模板库的旧标准）。
- **数据**：`selectedStandard`、`boundaryConfig`、`loadBjStandardsFromLibrary()`、`hasCycleConfig`。
- **验收**：[ ] 无配置时走引导并固定 DB11/T 1787-2020；[ ] 基准年为空；[ ] 标准列表只含 7 项 DB11/T；[ ]（目标态）已有配置时直达结果页

### B-02 确认主体信息
- **交互**：带出重点排放单位（小米汽车）/行业（汽车）/核算周期（按月度核算、年度报告；纳入北京碳交易管理）/因子库（含北京指定因子）；回复「确认主体信息」。
- **数据**：`orgInfo`、`factorDatabases`。
- **验收**：[ ] 对象为「重点排放单位」；[ ] 因子库含「北京指定因子」。

### B-03 确认排放源清单
- **交互**：清单 = **资源台账抽象**（`bjc_resources_v3`）+ **智能体侧清单**（手工新增 / 上传识别补录，`bjc_sources_v1`，不写台账）。北京口径 5 个排放源（直接排放：化石燃料燃烧 3 个；间接排放：消耗外购电力 1 个 + 消耗外购热力 1 个）；提供「上传台账识别」补录（覆盖只到品种的排放源）；可增删改；变更对话同步。
- **边界**：不含范围三（北京标准无此口径）。
- **数据**：`emissionSourceList`、`org_resources_v3`。
- **验收**：[ ] 清单为北京口径 5 个排放源；[ ] 无范围三项。

### B-04 标准分册选择
- **交互**：标准下拉含 7 项 DB11/T（电力/水泥/石化/热力/服务/道路运输/其他行业）；选定后 `applyStandardBoundary()` 重建边界（直接排放 + 间接排放）；版本从标准库带出（2020版）。
- **边界**：版本来源唯一（标准库）；发布年份 `yearNum=2020`；边界项为标准口径全列。
- **数据**：`standards`（BJ 场景）、`configuredStandardVersion`。
- **验收**：[ ] 7 项分册可选；[ ] 版本自动带出 2020版；[ ] 边界为直接/间接排放。

### B-05 确认核算模型
- **交互**：①清单×②边界自动匹配（直接排放：1号锅炉/2号锅炉/涂装线直燃机；间接排放：厂区总表/厂区热力表）；回复「确认核算模型」。
- **数据**：`emissionModel`（北京口径）。
- **验收**：[ ] 模型按直接/间接排放组织；[ ] 只读。

### B-06 启用周期核算
- **交互**：启用→四段式叙事→跳结果页→播报当期摘要（范围构成为「直接排放 X% · 间接排放 Y%」、对比为「较上年」）。
- **数据**：`currentCycle`、`resultTotals`。
- **验收**：[ ] 摘要口径为直接/间接排放；[ ] 对比为较上年。

### B-07 对比基准自适应
- **交互**：`needBaseYear()` 对 DB11/T 系列返回 false → KPI 第 4 卡显示「较上年」、趋势折线名「上年同月」、②不显示基准年（改显示「对比基准：上年同期」）。
- **数据**：`needBaseYear()`、`resultBaseline`（`isLastYear` 标记）。
- **验收**：[ ] 全页面无「基准年」字样；[ ] 对比用上年。

### B-08 结果与数据（北京口径）
- **交互**：KPI（总量/完整度/同比/环比）；趋势（直接排放+间接排放堆叠柱+上年同月折线）；构成（直接/间接排放）；贡献（消耗外购电力排放/化石燃料燃烧）；数据清单（按直接/间接排放分组，因子来源标注「北京市主管部门指定因子」）。
- **数据**：`resultTotals`、`resultTrendYear`、`resultScopeTable`（北京口径）。
- **验收**：[ ] 全链路无「范围一/二/三」；[ ] 因子来源为北京指定因子。

### B-09 年度视图
- **交互**：粒度切换；年度由月度汇总；数据清单按月页签；趋势近 5 年。
- **数据**：`resultGranularity`、`resultYearMonths`。
- **验收**：[ ] 年度=月度汇总；[ ] 较上年对比。

### B-10 核查对接
- **交互**：结果引导语「推荐核查机构」按钮，点击后对话内返回名单（5 家：CQC/SGS/BV/TÜV/中环），按「北京市碳排放权交易管理办法」的核查要求。
- **边界**：模拟接口延迟 900ms；名单来自核查机构库。
- **数据**：`verificationOrgs`、`showVerificationOrgs()`。
- **验收**：[ ] 按钮存在；[ ] 返回 5 家机构（资质/核查范围/评级报价/联系方式）。

### B-11 数据质量与缺失补充
- **交互**：完整度 KPI 显示「缺 1 项」；缺失项为「消耗外购热力排放 · 厂区热力表」；「补充缺失数据」进入补充。
- **数据**：`resultCompleteness`、`resultMissingItems`。
- **验收**：[ ] 缺失项为厂区热力表（北京口径）。

### B-12 锁定 / 导出 / 报告
- **交互**：悬浮操作栏三按钮（锁定/导出/报告）。
- **数据**：`isPeriodFiled`。
- **验收**：[ ] 三按钮可用。

### B-13 历史对话栏
- **交互**：会话记录、切换、删除、可收缩。
- **数据**：`conversationHistory`。
- **验收**：[ ] 会话记录、切换、删除正常。

### B-14 数据清单与参数溯源抽屉

- **交互**：清单按「范围 → 排放单元 → 参数表」组织；子项卡片整卡可点，打开右侧溯源抽屉。
- **数据清单**：3 列（参数名称 / 参数值 / 来源 · 佐证材料），参数按计算式顺序编号（活动数据 / 排放因子 / 折算参数），卡片底部计算式块；默认展开、可折叠。
- **抽屉结构（两段式）**：上段「计算参数」单列表（符号 AD/EF/P + 名称 + 值 + ✏️，可选中，符号配色区分类型）；下段随选中参数展示 **凭证材料 / 匹配过程 / 更正记录** 三段。
- **数据**：`traceRow`、`activeParam`、`paramMatchInfo()`、`paramEditLog`。
- **验收**：`[x]` 参数选中联动下段；`[x]` 三段随参数切换；`[x]` 因子类提示无需凭证。

### B-15 参数更正与留痕

- **交互**：✏️ → 弹窗（名称/原值只读，新值/理由必填，佐证附件）→ 保存；写 `emissionModel` 源值并重算，留痕入 `paramEditLog`；锁期只读。
- **验收**：`[x]` 值变化并重算；`[x]` 记录页留痕；`[x]` 锁期拦截。
