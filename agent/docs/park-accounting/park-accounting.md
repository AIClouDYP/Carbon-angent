## 1. 业务场景定位

面向零碳园区建设主体（园区管委会/运营方），按附件4核算**园区级**二氧化碳排放（原型单位 tCO₂），并按附件3进行 **1 核心 + 5 引导**指标对标监测。

**与组织/北京场景的关键差异**：

| 维度 | 组织 | 北京 | 园区 |
|---|---|---|---|
| 核算对象 | 排放源→排放单元 | 同左 | **四大法定分类（含工业过程按产品归口）** |
| 分类骨架 | 范围1/2/3 | 直接排放/间接排放 | **化石燃料燃烧 / 能源加工转换 / 净购入电力热力 / 工业过程** |
| 特有机制 | 基准年对比 | 上年对比 | **0 因子核减（光伏自用/绿电绿证）+ 1+5 指标裁剪** |
| 气体/单位 | 7种GHG / tCO₂e | CO₂ / tCO₂ | **仅CO₂ / tCO₂（原型演示；申报口径万吨）** |
| 数据来源 | 企业计量台账 | 同左 | **双渠道：底座数据识别 + 材料识别** |

## 2. 核算体系（附件4）

```
E_园区 = E_能源活动 + E_工业过程                    （仅 CO₂）

E_能源活动 = E_用作燃料 + E_加工转换 + E_净受入
  ├─ E_用作燃料 = Σ(品种消费量 × 因子)
  ├─ E_加工转换 = Σ(投入×因子) − Σ(产出×因子)        （碳平衡，氧化率 100%）
  └─ E_净受入   = E_电(受入−送出) + E_热(受入−送出)
        · 绿电直供/绿证 → 因子 = 0；其余按区域电网因子
        · 非化石热力 → 因子 = 0

E_工业过程 = Σ(产品产量 × 因子)                     （晶圆/电芯按产品归口）
```

## 3. 页面功能（当前实现）

### 3.1 对话引擎（已适配）
- **三步 · 五项确认**，严格顺序：
  - ① 园区主体与依据：确认园区信息 → 确认核算标准（附件4 + 1+5 指标体系 + 核心门槛分档）

- **思考过程 + 结论同条消息**（默认折叠，nextTick 滚动贴底）
- **双向联动**：页签/步骤/粒度/期次切换互相同步播报（_silentSwitch 抑制重复）
- **统一意图**：确认五项、启用周期核算、指标裁剪说明、上传台账识别、清单来源、指标问答（1+5 对标全文）等

- 步骤 1 园区主体与依据：基础信息编辑（面积/能耗规模两档/企业数）+ 标准联动 + **指标裁剪（适用/豁免+理由）**
