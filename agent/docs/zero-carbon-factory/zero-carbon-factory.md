# 零碳工厂申报工作台（/#/agent-center/apps/zero-carbon-factory）

> 模块：zero-carbon-factory | 主文件：accounting/agent.vue（两种页面模式：首页 task-list / 任务编排 task-active，见 [TaskWorkbench.md](TaskWorkbench.md)）
> 对应标书：2.7.7 零碳工厂智能体 | 本文覆盖**首页（task-list）**；任务编排另见 [TaskWorkbench.md](TaskWorkbench.md)

## 1. 业务场景定位

面向创建零碳工厂的制造企业与算力设施运营方，按照零碳工厂评价标准完成创建水平的量化评价与申报材料编制。首页是申报任务的入口与管理中心：输入「开始申报」或点击历史申报卡片进入任务编排。

## 2. 页面布局

本页为首页（task-list 模式）；点击任务进入任务编排（task-active 模式）见 [TaskWorkbench.md](TaskWorkbench.md)。三栏：

```
┌──────────┬────────────────────────────┬──────────────┐
│ 历史对话  │  对话区（欢迎态）           │ 历史申报     │
│ (默认收缩)│  欢迎语 + 新手引导          │  ┌──────────┐│
│          │  快捷指令面板 / 输入框      │  │任务卡片   ││
│ 会话记录 │  历史任务卡片（指令呼出）   │  │状态/阶段  ││
│          │                            │  └──────────┘│
└──────────┴────────────────────────────┴──────────────┘
```

- 左：历史对话栏（默认收缩为竖排边条，点击展开；支持切换/删除/新建）
- 中：对话区，欢迎态承载引导与指令入口；输入「历史记录」可在对话内呼出历史任务卡片
- 右：历史申报窄栏（任务卡片：状态 tag / 当前阶段 / 进度条 / 更新时间 / 删除）

## 4. 功能点详情

> 对照第 3 节清单逐项展开。任务编排（六阶段 / 四道确认）见 [TaskWorkbench.md](TaskWorkbench.md)。

### Z-01 申报项目管理（右栏）
- **交互**：
  - 点击任务卡片 → 加载对应案例数据（loadCase：制造型 / 算力设施双套）→ 恢复阶段进度 → 进入任务编排
  - 删除：el-popconfirm 确认后移除并持久化（deleteTask / saveTasks）
  - 任务卡展示：状态 tag（进行中 / 已完成）、主体类型、当前阶段、进度条、更新时间
- **边界**：同企业 + 同基准年再次新建时提示「进入已有任务」（防重复，confirmNewTask）
- **数据**：taskList（zcf_task_list 持久化，seedVersion 控制演示任务版本清理）
- **验收**：[ ] 任务新建后出现在右栏并持久化，刷新不丢；[ ] 点击卡片恢复到任务离开时的阶段

### Z-02 历史对话栏（左栏）
- **交互**：
  - 展开收缩：默认收缩为竖排边条，点击展开
  - 会话切换 / 删除 / 新建对话（newConversation：清空消息回欢迎态）
- **边界**：会话仅内存态，刷新后清空（当前未接入持久化，与智慧报告工作台不同）
- **数据**：conversationHistory（内存态）
- **验收**：[ ] 收缩展开正常，切换 / 删除 / 新建可用

### Z-03 对话区（中栏·主体）
- **交互**：
  - 欢迎：欢迎语说明任务来源（主管部门/期次/频次三要素自动流转）+ 建议按钮「开始申报」
  - 快捷指令面板（灯泡呼出，2 组）：申报操作（开始申报 / 历史记录）；信息查询（指标分类 / 基础库 / 溯源链）
  - 对话指令：「新建/开始/申报或企业名」→ 打开新建任务弹窗；「历史/记录」→ 对话内渲染历史任务卡片（点击 continueTask 进入）；「指标/分类」「库」「溯源」→ 返回信息卡片；未知输入回提示清单
- **数据**：tlMessages（内存消息流）、getIndicatorTypeInfo / getLibraryInfo / getTraceabilityInfo（静态信息卡）

### Z-04 新建申报任务弹窗
- **交互**：
  - 申报依据：planVersions 下拉（政策版本）
  - 企业名称：按所选依据自动带出（autoFactoryName，只读）
  - 基准年：date-picker，与政策要求基准年不一致时 warning 确认——确认按钮「继续使用（试算）」、取消按钮「恢复为 XXXX 年」（按政策基准年**动态取值**），文案同时提示「与政策文件要求不一致可能导致申报材料不被受理」
  - 申报主体类型：制造型 / 算力设施（决定 loadCase 案例分支）
  - 提交：confirmNewTask 创建任务 → saveTasks 持久化 → 进入任务编排
- **边界**：同企业 + 同基准年已存在任务 → info 提示「进入已有任务」，不重复创建
- **数据**：planVersions、newTaskPlan、autoFactoryName
- **验收**：[ ] 企业名与依据联动带出；[ ] 基准年不一致时弹确认；[ ] 重复任务被拦截

### Z-05 新手引导
- **交互**：header「新手引导」按钮触发；首次访问（无 zcf_onboarding_done）自动弹出
- **数据**：zcf_onboarding_done（localStorage，完成即写）
- **验收**：[ ] 首次访问自动弹出，完成后不再弹出

### Z-06 上下文用量估算
- **交互**：输入区徽标展示估算值（k / 万 tokens 格式化），有消息时才出现；新建对话清零
- **边界**：中文字符≈1.5 token 折算，水位提示非精确计数、非计费（tooltip 已注明）
- **数据**：estimatedTokens（由 tlMessages 派生）

### Z-07 多模态输入（待开发）
- **现状**：语音 / 图片 / 附件三个入口，点击仅提示「开发中」
