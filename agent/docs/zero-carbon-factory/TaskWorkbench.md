# 零碳工厂任务编排（agent.vue 任务模式）

> 隶属模块：zero-carbon-factory | 入口：首页（task-list）点击任务卡片或新建任务进入
> 对应标书：2.7.7 零碳工厂智能体 | 本文覆盖**任务编排（task-active 模式）**；首页另见 [zero-carbon-factory.md](zero-carbon-factory.md)

## 1. 业务场景定位

单个申报任务的工作现场：以对话区为引导、右侧六阶段面板为工作面，按「标准规则适配 → 核算模型搭建 → 数据收集与校验 → 指标核算与评价 → 建设目标与优化建议 → 材料编制与数据溯源」推进。四道关键确认均为用户签字负责节点，确认后锁定方可进入下一阶段。

## 2. 页面布局

两栏（task-active 模式）；header「返回」回到首页，「重置」重开当前任务。

```
┌──────────────────────────────┬───────────────────────────┐
│ 对话区                        │ 顶部：六阶段进度条          │
│ 任务欢迎语 + 阶段引导          │   （回看横幅 / 需确认标记） │
│ 建议按钮（仅最新一条消息）     │ 中部：当前阶段面板          │
│ 快捷指令面板（3 组）           │   （phase-detail 0~5）      │
│ 输入框                        │ 底部：悬浮统一确认栏        │
└──────────────────────────────┴───────────────────────────┘
```

六阶段面板为条件渲染子视图（phase-detail 0~5），同一时刻仅显示当前阶段；各阶段内容形态见 ZC-02~ZC-07。

- 对话区快捷指令面板（3 组）：流程操作（下一步 / 查看进度）· 信息查询（指标分类 / 基础库）· 阶段功能（资格诊断 / 建设目标 / 材料下载）
- 输入区工具条：快捷指令（呼出面板）· 语音输入 / 图片上传 / 附件上传（三者点击提示「开发中」，见 Z-07 口径）

## 4. 功能点详情

> 对照第 3 节清单逐项展开。阶段面板的业务数值均为预置演示数据（mock），阶段推进状态机 / 确认留痕 / 任务持久化为真实逻辑。

### ZC-01 阶段进度条与回看（右栏顶部）
- **交互**：
  - 节点三态：完成 ✓（track-done）/ 当前（track-active）/ 下游失效（track-invalidated + 刷新图标「需确认」）
  - 回看：点击已完成节点回看（currentStepIndex < maxStepIndex 时显示回看横幅）；「保存修改」标记下游阶段失效（saveHistoryEdit 重建 invalidatedStages）并跳回最高阶段
  - 失效消除：需逐级重新走完该阶段确认（nextPhase 成功时 clearInvalidated）
- **边界**：回看模式对话推进被拦截（提示正处于回看模式）；仅 idx ≤ maxStepIndex 可跳；跳到最高阶段才回写任务进度（防回看污染进度）
- **数据**：currentStepIndex / maxStepIndex / invalidatedStages（内存态，重进任务时重置）
- **验收**：[ ] 回看编辑保存后下游节点出现「需确认」；[ ] 回看模式对话推进被拦截；[ ] 重新确认后失效标记逐级消除

### ZC-02 标准规则适配【确认①】（阶段面板 0）
- **交互**：
  - 标准适配卡：申报依据 / 主体类型 / 基准年（首页带入）
  - 指标体系卡：5 大类 11 项指标与适用性规则（indicatorSysExpanded 展开；算力案例含适用性豁免）
  - 企业基本信息卡：11 项（baseInfo 自动带出、可编辑）
  - 资格条件三段：静态硬资格 / 量化条件 / 负面清单（要求 / 现状 / 材料 / 判断四列）；证明材料池关联（linkProof / uploadNewProof）、承诺书模板下载（downloadCommitment）、逐项判定（judgeQualiPass）与结论条（qualiConclusion）
- **边界**：资格条件不通过 → 底部确认拦截（$message.warning），无法进入阶段 1
- **数据**：phaseDetails[0]（mock）、qualification.proofPool
- **验收**：[ ] 资格条件不通过时确认被拦截；[ ] 确认后写入关键留痕时间线

### ZC-03 核算模型搭建【确认②】（阶段面板 1）
- **交互**：
  - 三级结构编辑：排放源构成明细（add/removeEmissionSource）、生产过程卡（输入输出增删 addProcessIO）、派生节点只读绿标签（E₁ / E₂ / Ez / Q）
  - **可维护项口径**：化石燃料燃烧排放源 / 购入电力排放源（按购电来源）/ 物理电力来源 / 生产过程（多输入多输出）/ 碳清除方式；**派生项**（E₁ / E₂ / Ez / Q、购电认定量、工业增加值、装备功率、直接排放量等）由上游自动联动生成，不手工维护
  - 联动：排放源改动同步派生能源品种（syncE1Sources）
  - 口径说明：模型项名称带 **ℹ 图标**，悬浮查看口径与联动说明
  - **材料识别 · 自动建模**：支持上传能源台账 / 购电合同 / 物理消纳凭证 / 工艺说明 / 设备清单 / 核查报告 / 产品清单（B204-1），识别后自动生成对应构成明细——点击阶段建议按钮或输入「上传XX」触发
  - 核算方法：**购入电力 a / b / c 三方法**在阶段 4 数据接入后试算推荐
  - 填报指标：独立 model-group 分组（fillMode），构成明细列显示填报项
- **边界**：材料识别的识别结果为**演示数据**（以预置映射生成构成明细，非真实文件解析）；派生项只读、不可手工改写
- **数据**：phaseDetails[1].indicatorModels（mock，11 项指标归属）
- **验收**：[ ] 排放源增删与 E₁ 派生联动正确；[ ] 材料识别可生成对应构成明细；[ ] ℹ 图标悬浮可查看口径说明；[ ] 确认后留痕「确认核算模型三级结构、指标归属与计算路径」

### ZC-04 数据收集与校验（阶段面板 2）
- **交互**：
  - 双页签（phaseOps.dataTab）：待处理清单 / 活动数据与因子
  - 待处理清单：逐项填报或确认（handleValItem，空值拦截）、凭证关联 / 上传（linkValProof）、清单下载（downloadValChecklist）、演示附件上传（uploadValFile）
  - 活动数据网格：指标 → 子模块 → 行三级，每行活动数据 + 匹配因子、来源列与关联按钮（linkCollectProof）
- **边界**：待处理事项未清零（pendingValCount > 0）→ 底部确认与对话「下一步」双重拦截
- **数据**：validationItems / collectModel（mock）；missing → resolved 状态流转真实
- **验收**：[ ] 待处理清零前确认与对话推进均被拦截；[ ] 填报 / 判定 / 数据三类行徽标区分正确

### ZC-05 指标核算与评价【确认③】（阶段面板 3）
- **交互**：
  - 核算结果表：11 项指标（当前值 / 基本要求 / 目标要求 / 评价结果 tag）
  - 核算明细（accDetailExpanded 收缩）：计算指标逐行验算式（值 × 因子 = 结果 + 小计 + 合计）；填报指标（fillMode）与披露判定指标（judgeMode）直接渲染填报行
- **边界**：两级判定——核心 3 项按目标 / 基本要求判定，其余 8 项持续改善核查（不设量化要求）
- **数据**：indicators / accountingDetails（mock 预置结果，无总分 / 星级计算）
- **验收**：[ ] 确认后留痕「确认 11 项指标核算结果与核心指标评价结果」

### ZC-06 建设目标与优化建议（阶段面板 4）
- **交互**：
  - 期末目标表：建设期起止年（goalEndYearModel）+ 核心 / 自评分组行（phase5GoalGroups，roundGoal 取整，核心 3 项锚定官方要求）
  - 年度分解：goalMidYears × 各指标年度值可编辑，改期后线性插值重分解（changeGoalPeriod）
  - 确认后追加：差距分析表（phase5GapGroups，差距红字）、改善措施推荐卡（toggleAdoptMeasure，默认全采纳）、申报诊断卡
  - **申报场景自动判定**：阶段 4 核心指标全部满足目标要求 → 场景「巩固提升」，否则 → 「改善中」（applyAutoScenario，随阶段 5 生效）
  - **降碳措施减排量测算**：改善措施按统一四方向标注（新能源建设 / 设备升级改造 / 余能利用 / 碳抵消）；每条措施可编辑测算参数（绿电电量、装机容量与年等效利用小时数、年节电量、可回收余热量、年抵销量），配典型减排系数（电网 0.581 tCO₂/MWh、热力 0.11 tCO₂/GJ）→ **实时测算年减排量**（measureReduction），参数调整即联动更新；管理类差距项另以「管理提升」措施保留（无参数、不参与测算）；措施以**表格**呈现（类别 / 降碳项目 / 项目内容输入 / 项目年均减排量 / 是否采用开关），仅计算减排量，不含成本收益项
  - **减排效果汇总与目标对照**：已采纳措施合计年减排量 + 四方向分解 + 测算/管理类计数（adoptedMeasureSummary）；逐条目标差距项对照已采纳措施（goalMeasureCompare，无对应措施显示 —）
- **边界**：测算系数与参数默认值为演示数据（系数为内置典型口径，平台不新建措施库）；其余场景（非零碳工厂）仅给大方向建议、不做测算；管理类差距项保留对应措施（方向标注「管理提升」，不参与减排量测算，汇总中单列计数）；目标确认（toggleGoalConfirm）后期末目标与年度轨迹输入锁定；「调整目标」（面板标题区或指令）解锁并重新引导；建设期起始年不晚于基准年时确认拦截；**场景由系统自动判定，不暴露切换 UI**
- **数据**：phaseDetails[4] / consolidateScenario（mock）；measures[] 含 direction / params / factor / calcType / targetIndicator，减排量由 measureReduction 实时计算（不落库）
- **验收**：[ ] 目标确认后输入锁定；[ ] 调整目标后需重新确认才能生成改善计划；[ ] 四方向措施均可编辑参数并测算减排量；[ ] 调整测算参数后单条与合计减排量均联动更新；[ ] 目标差距项正确对照到已采纳措施

### ZC-07 材料编制与数据溯源【确认④】（阶段面板 5）
- **交互**：
  - 整篇方案编制弹窗（1080px）：左目录（状态 tag，jumpToPreviewSection 锚点跳转）+ 右章节（auto 章只读占位符高亮；draft 章 textarea 编辑 + AI 润色 polishSection + 保存本章 saveSectionEdit）；动态表格（getTableRows / getTableColumns）
  - 四级证据链：统计卡 + 溯源明细表（evidenceParamRows 由阶段 3 采集数据真实聚合）+ 三级链卡（计算过程 / 输入参数 / 可信度）+ HTML 报告下载（downloadEvidenceReport）
  - 关键留痕：el-timeline 渲染 confirmRecords（四道确认）
  - 归档与导出：方案存档（handleArchiveReport → isReportArchived，按钮锁死「已归档至碳报告中心」、任务置 completed）、导出 PDF / Word、专家复核（handleShareReport，仅提示）
- **边界**：归档不可重复（isReportArchived 拦截）；AI 润色为静态映射演示；导出 / 分享仅提示未产文件
- **数据**：materialSkillConfig（方案七章配置）、evidenceParamRows（真实聚合）、confirmRecords（内存态）
- **验收**：[ ] 四道确认全部出现在关键留痕时间线；[ ] 归档后按钮锁定且任务在首页标记已完成

### ZC-08 会话重置（对话区 header）
- **交互**：header「重置」→ resetSession：currentStepIndex / maxStepIndex 归 0、phaseOps 全清、invalidatedStages / confirmRecords / isReportArchived 清空、phaseDetails 恢复初始快照、任务 status 回 active、对话重置为阶段欢迎语
- **边界**：不影响 taskList 中其他任务
- **验收**：[ ] 重置后从阶段 0 重新开始，数据恢复初始快照

### ZC-09 任务进度回写（对话区）
- **交互**：阶段推进 / 对话回复末尾 updateTaskProgress 同步 taskList（阶段 / 进度 / messages）；首页点击卡片 continueTask 从断点恢复（消息回放、案例数据 loadCase 深拷贝）
- **边界**：回看模式下不回写（防回看污染进度）；双案例（制造型小米汽车工厂 / 算力设施绿算智算中心）各自独立快照
- **数据**：taskList（zcf_task_list 持久化）、phaseDetails / computingPhaseDetails 双套案例 mock
- **验收**：[ ] 中断任务重进后从断点阶段继续，对话上下文回放
