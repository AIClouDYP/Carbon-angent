# Carbon-Agent · 零碳园区智慧能碳服务平台

面向零碳园区的智能碳核算平台前端，包含产品碳足迹、产品环境足迹、组织碳核算、北京碳市场、园区碳核算、绿色工厂、零碳工厂、智慧报告等多场景智能体。

## 技术栈

- Vue 2.7（实装 2.7.16）+ Vue CLI 5
- Element UI 2.15
- ECharts 5
- Vue Router 3

## 快速开始

```bash
cd agent
npm install
npm run serve      # 开发服务，默认 8080
npm run build      # 生产构建，输出 dist/
```

## 主要场景

### 产品碳足迹（九阶段 LCA 核算，主场景）

| 阶段 | 名称 | 说明 |
|---|---|---|
| 1 | 政策标准 | 核算标准选择与政策条款解析 |
| 2 | 核算边界 | 生命周期范围、量化单位、分配与取舍规则 |
| 3 | 核算模型 | 工艺拓扑构建与单元过程建模 |
| 4 | 活动数据 | 多源活动数据并发采集 |
| 5 | 排放因子 | 排放因子库自动匹配绑定 |
| 6 | 数据校验 | 完整性、一致性、趋势、DQR 多重校验 |
| 7 | 碳足迹计算 | 全生命周期碳排放量汇总计算 |
| 8 | 碳足迹分析 | 统计分析、不确定性分析与敏感度分析 |
| 9 | 碳足迹报告 | 核算报告生成、数据溯源与核查推荐 |

### 其他场景

- **产品环境足迹**：基于产品碳足迹扩展的多类别环境影响评估，支持欧盟 PEF 方法论
- **组织碳核算**：九阶段流程（含组织边界、基准年、排放因子库配置）
- **北京碳市场**：北京地方标准管控
- **园区碳核算**：九阶段（政策标准 → 核算边界 → 排放源清单 → 活动数据 → 排放因子 → 数据校验 → 排放计算 → 排放分析 → 排放报告）
- **绿色工厂**：四阶段自评价（标准规则适配 → 数据收集与校验 → 指标核算与评价 → 数据溯源与材料归档）
- **零碳工厂**：六阶段申报流（资格确认 → 指标核算 → 数据采集 → 指标结果 → 差距分析 → 材料清单）
- **智慧报告**：按部门/频次/期次模板化生成碳相关报表，支持合规校验

## 因子库

- **排放因子库**：CPCD / IPCC / GWP / Ecoinvent / ELCD / 国家温室气体排放因子库
- **企业因子库**：企业实测私因数（企业自建，与企业因子库分库管理）
- **分时分区电碳因子库**：省级/市级 × 小时级电力碳强度，支持 CSV 模板导入与数据质量校验
