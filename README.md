# Carbon-Agent · 零碳园区智慧能碳服务平台（智能体前端）

面向零碳园区的智能碳核算平台前端，包含产品碳足迹、组织碳核算、北京碳市场、园区碳核算、零碳工厂、报告提报等多场景智能体。

## 技术栈

- Vue 2.7 + Vue CLI 5
- Element UI
- ECharts 5
- Vue Router 3

## 目录结构

```
agent/
├── src/
│   ├── pages/zcip/               # 业务场景
│   │   ├── agent-center/         # 应用中心、资源台账、运维管理
│   │   ├── park-accounting/      # 园区碳核算（含九阶段）
│   │   ├── org-accounting/       # 组织碳核算
│   │   ├── beijing-carbon/       # 北京碳市场
│   │   ├── pef-accounting/       # 产品环境足迹
│   │   ├── footprint/            # 产品碳足迹
│   │   ├── zero-carbon-factory/  # 零碳工厂
│   │   └── report-submission/    # 报告提报
│   ├── components/               # 通用组件
│   ├── config/                   # 智能体注册配置
│   ├── router/                   # 路由
│   └── utils/                    # 工具（因子匹配服务等）
└── package.json
```

## 快速开始

```bash
cd agent
npm install
npm run serve      # 开发服务，默认 8080
npm run build      # 生产构建，输出 dist/
```

## 主要场景

### 园区碳核算（九阶段）

| 阶段 | 名称 | 说明 |
|---|---|---|
| 1 | 政策标准 | 标准解析与指标体素提取 |
| 2 | 核算边界 | 园区主体、边界、年度、产品、因子库 |
| 3 | 排放源清单 | 四大法定分类 + 指标底账参数 |
| 4 | 活动数据 | 底座直连 + 材料识别双通道采集 |
| 5 | 排放因子 | EF 排放因子 + CEF 折标煤系数匹配 |
| 6 | 数据校验 | DQR 质量评估 + 数据清单 |
| 7 | 排放计算 | 四大分类逐项计算 + 指标参数 |
| 8 | 排放分析 | 构成、贡献排行、指标达标评价 |
| 9 | 排放报告 | 零碳园区建设自评报告 |

### 其他场景

- **产品碳足迹**：九阶段 LCA 核算，支持多标准路由
- **组织碳核算**：三步配置 + 四项确认
- **北京碳市场**：北京地方标准管控
- **零碳工厂**：六阶段申报流

## 因子库

- **排放因子库**：CPCD / IPCC / GWP / Ecoinvent / ELCD / 国家温室气体排放因子库
- **企业因子库**：企业实测私因数
- **分时分区电碳因子库**（规划中）：省级/市级 × 小时级电力碳强度
